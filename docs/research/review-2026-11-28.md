# 整体回顾（2026-11-28）：站在整个游戏的角度

用户：每做一段就停下来，整体 review。看看有没有因为陷进细节而忽略了游戏的整体性、有没有偏离游戏本身。要看宏观的逻辑和玩法，不纠技术细节。

## 一、这个游戏是什么（对照 GDD 的愿景校准）

- 一句话：设计一种动物，看世界怎么"验收"它，再用兽医的手段收拾它留下的烂摊子。
- 主线乐趣是"验收"：设计是假设，世界是实验。
- 一局的样子：来信 → 设计台 → 投放到岛上 → 岛上过日子（看、查、干预）→ 验收和回信 → 回到家 → 下一封信。
- 生日版的过关问题：她能不能不看说明，从头玩到尾，愿意再玩一遍？

## 二、过去两周的时间花在哪里

最后一个推进主循环的提交是 11-15（专利证书、声音、扑食）。从那以后：

| 时间 | 做了什么 | 属于 |
|---|---|---|
| 11-17 – 11-21 | 美术重定向、纸剧场第一版、3D 纸剧场原型、纸雕岛原型 | 画面 |
| 11-22 – 11-27 | 工作室方向稿、车「勾勾」（概念 → 3D → 三视图建模 → 可编辑导出） | 家的画面 |
| 11-27 | 计量模块（课本例题）、纸偶参数化两批、植物图鉴、植物进剧场、零件拓扑 | 设计台、世界的画面 |

**结论**：两周里玩家能玩的主循环几乎没变。
- 鸟岛的委托、兽医、委托序列，都还停在 11-15 的样子；
- 离生日大约三周半；
- 这是复盘里写过的老问题（"在一个系统里越磨越细"）第四次出现：这次磨的是画面——车、纸偶、植物。

## 三、两个具体的偏离

### 1. 剧场：已经决定退役，又被继续加厚

- 11-22 已经定了：纸剧场盒子退役，桌上的 A4 纸雕岛就是地图的入口，点它走进全屏的岛（DECISIONS"工作室是游戏的家"）。
- 但游戏本体里还在用 11-21 的纸剧场，这周我还往里面加了植物。这是做之前没有对照已有的决定。
- 用户的判断是对的：剧场是另一套体系，壳本身没有玩法。
  - 要看近处：就在同一个岛上拉近，这也是铁律 2 的原意（远处按格子算，近处展开成个体）；
  - 要剪视频：在同一个场景里走镜头就行，不需要一个剧场的壳。
- **做法**：
  - 去掉剧场；
  - 游戏里的岛换成纸雕岛（three.js，和车里托盘上的是同一座）；
  - 动物是 3D 纸偶，在岛上走，拉近就是近景；
  - 植物图鉴直接长在纸雕岛上。

  这周给剧场做的三排植物，逻辑（哪一带长什么、被啃了怎样）原样搬到岛上，只是不再分排。

### 2. 毛色遗传：放在现在的循环里，玩家感受不到

先说实话：现在的主循环里没有一个地方能让玩家注意到它。
- 每次投放，玩家只看三年；
- 验收单上只有只数和死因；
- 岛上同时有几十只，颜色慢慢变，没人会盯着看。

它要能被感受到，得同时满足三件事：玩家在意颜色、颜色有后果、后果被指给他看。在游戏里能对上的地方是：

- **专利和实物不符**：专利证书上写着"沙色"，三年后岛上大半是深色，回信或者审查员会说"实施例与权利要求不符"。这是"世界验收了你的设计，还改写了它"，很对这个游戏的味道。
- **一份专门的委托**：比如"岛上的猫靠眼睛抓东西，鸟被吃光了"，玩家可以设计一种保护色的鸟，或者干脆研究自然选择。
- **前提**：要在岛上一眼认得出颜色变了，而且有一张"这一季的毛色比例"的小条。

**判断**：它不是核心乐趣，是课本知识的一个落点。生日前不做；放进想法池，等主循环和兽医都跑通以后，再作为一份委托的主题来做。

## 四、接下来的顺序（提议）

| 段 | 做什么 | 结束时的整体 review 问题 |
|---|---|---|
| A（约 4 天） | **一个世界**：<br>• 游戏里的岛换成纸雕岛，去掉剧场；<br>• 3D 纸偶在岛上走，拉近看个体；<br>• 植物长在岛上 | 从家到岛、拉远拉近，是不是同一个地方？等待的时候有东西看吗？ |
| B（约 5 天） | **兽医**：<br>• 在岛上抓一只 → 拿回车里的台面上体检、采样 → 化验 → 处理；<br>• 病和寄生虫从推演里来（先一种） | 兽医是不是"收拾自己设计留下的烂摊子"？有没有变成实验室模拟器？ |
| C（约 5 天） | **一局变成游戏**：<br>• 鸟岛委托（身体决定被不被猫抓）；<br>• 委托序列；<br>• 家（勾勾）接进来 | 不看说明能从头玩到尾吗？ |
| D（最后一周） | 只修不加 | 可以交了吗？ |

- 纸偶的零件拓扑、Lovart 的素材回来以后的替换，穿插在 A–C 里做，每次不超过半天。
- 车（勾勾）的接入等用户改完模型，放在 C。

## 五、以后每段结束都做的整体回顾（固定问题）

1. 这一段做完，玩家能玩的东西有什么变化？一句话说得出来吗？
2. 这一段的时间，多少花在了主循环上，多少花在了画面和细节上？
3. 有没有做和已有决定（DECISIONS、ROADMAP）冲突的事？
4. 主线乐趣（验收）这一段有没有变强？
5. 有没有在一个系统里越磨越细？
6. 离生日还有多少天，剩下的顺序要不要调？

## 六、A 段结束的回顾（2026-11-28 晚）

1. **玩家能玩的东西变了什么？** 岛从一张俯视的剪纸地图换成了纸雕岛：动物是站在纸板上的纸偶，植物是这一带真实的植物，拉近就是近处。剧场的壳没有了。
2. **时间花在哪？** 几乎都花在"一个世界"上，没有去磨纸偶和植物的细节。中间一大块时间耗在截图调试上：软件渲染很慢，还有共用材质透明度那个问题。
3. **有没有和已有决定冲突？** 没有，这一段执行的就是 11-22 定的"剧场退役、纸雕岛是地图"。
4. **验收这个主线乐趣变强了吗？** 间接变强了：动物在岛上"活着"更像一个地方。验收单、回信没有变。
5. **有没有越磨越细？** 没有，数据图层、近处展开成个体都没做，留到需要的时候。
6. **顺序要不要调？** 不调，接着做 B（兽医）。B 是空白最大、离"兽医是主线的一半"最远的一块。
