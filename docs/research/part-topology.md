# 纸偶零件的拓扑：用很少的控制点调出典型形态

2026-11-27 用户：极端参数下动物有"喜感"不算问题。重点是各个零件的拓扑抽象怎么做好：每个零件不需要很多控制点，就能调出一些典型的形态。

## 一、为什么改

现在的纸偶是把 Lovart 那只猫的 23 片零件拉伸，贴到新的骨头上；猫身上没有的部位（长颈、角、腰、蹄）再由代码剪。问题有两个：

- **形状被锁在猫身上**：头永远是猫脸，长吻是拉长的猫鼻子，大腿是两个圆盘。
- **代码剪的零件和成品图零件是两套做法**，没有统一的抽象。

改成：**每一类零件都有一个固定的拓扑，加 3–6 个控制量**。
- 典型形态（猫的头、狐的头、熊的头、食蚁兽的头……）是同一个拓扑在控制量上取的点（预设）。
- 设计台的参数通过控制量起作用。
- Lovart 针对每类零件设计画法：纸的层次、色区、描边、铆钉的位置。形状本身由控制量决定。

这和耳朵的做法一样（`ear.ts`：半圆耳根 + 两侧对称 + 圆尖由 (a, b) 控制，5 个参数覆盖了从鼠耳到垂耳）。

## 二、共同的骨架：带"站点"的骨段

除了头、脚、耳、角，其余的零件都是同一种拓扑：

- **一根骨头**：从转轴（铆钉）指向下一个关节，长度 L。
- **沿骨头的 3–4 个站点**：每个站点有位置 t（0–1）、上沿的半宽和下沿的半宽，上下可以不对称。
- **两头是搭接的圆头**：圆心就是铆钉，半径等于这一头站点的宽。转起来不露缝。
- **轮廓**是用平滑曲线穿过所有站点的上沿和下沿，两头接圆头。
- **色区按轮廓推出来，不单独画**：
  - 浅色：下沿往里的一条带（背深腹浅）；
  - 条纹：沿骨头每隔一段一道，从上沿往下收尖。

|零件|骨头|站点（控制量）|典型形态|
|---|---|---|---|
|颈的一节|颈根 → 下一节|根宽、梢宽、喉部鼓出（3）|鼬的细颈、马的扁颈、野牛的粗颈|
|臀片|脊背中点 → 尾根|臀高、臀部圆度、大腿上沿（3）|猫的圆臀、马的斜臀、袋鼠的大臀|
|胸片|脊背中点 → 肩前|鬐甲高（肩峰）、胸深、前胸鼓出（3）|灵缇的深胸、野牛的肩峰、腊肠犬的浅胸|
|腰片|臀 → 胸|背线下凹、肚子下垂（2）|鼬的长腰、河马的垂肚|
|大腿、上臂|髋 → 膝|根宽、肌肉鼓出的位置和大小、梢宽（4）|猫的大腿、马的长大腿、熊的粗大腿|
|小腿、前臂|膝 → 踝|根宽、梢宽、腱的收细（3）|鹿的细小腿、熊的柱状腿|
|尾的一节|尾根 → 下一节|根宽、梢宽、毛的蓬松（3）|鼠的光尾、狐的蓬尾、袋鼠的粗尾|

## 三、头：头骨 + 吻 + 下颌

头是辨认一种动物最要紧的地方，单独设计拓扑。

- **头骨**：一个圆，半径 R。眼睛钉在头骨上，位置是头骨圆周上的一个角度（前上方），不随吻变。
- **吻**：从头骨前缘伸出的一个站点骨段。控制量：
  - 吻长 ÷ R；
  - 吻根的高（相对 R）；
  - 吻端的高（相对吻根）：管状吻接近 1，尖吻接近 0.3；
  - 吻端形状：从圆钝（熊、牛）到尖（鼩鼱），一个 0–1 的量；
  - 鼻梁的弯：凹（波斯猫、鹿）、直、凸（马、羊的"罗马鼻"），−1 到 1。
- **下颌**：吻的下沿往回一条细骨段，长度跟着吻，厚度是一个量（下颌粗壮：食蚁兽细、鬣狗粗）。
- **鼻垫**：吻端的一小片，跟着吻端走，不拉伸。

一共 7 个控制量：R、吻长、吻根高、吻端高、吻端形状、鼻梁弯、下颌厚。

| 典型形态 | 吻长 | 吻根高 | 吻端高 | 吻端形状 | 鼻梁 | 下颌 |
|---|---|---|---|---|---|---|
| 猫 | 0.45 | 0.7 | 0.7 | 0.4 | 0 | 0.3 |
| 扁脸（波斯猫） | 0.15 | 0.7 | 0.9 | 0.1 | −0.3 | 0.3 |
| 狐、狗 | 0.95 | 0.6 | 0.45 | 0.8 | 0 | 0.35 |
| 熊 | 0.75 | 0.85 | 0.7 | 0.1 | 0 | 0.5 |
| 马、鹿 | 1.6 | 0.8 | 0.55 | 0.3 | 0.3 | 0.4 |
| 食蚁兽 | 3.5 | 0.45 | 0.85 | 0.2 | 0 | 0.1 |
| 鼠 | 0.8 | 0.6 | 0.4 | 0.9 | 0.1 | 0.25 |

## 四、脚

脚是一个骨段（掌或跖），末端接一个"着地件"。控制量：

- 着地方式：跖行、趾行、蹄行，0–1；它决定脚着地时的角度，现在的 `stance` 已经有了；
- 脚掌长、脚掌宽；
- 趾的数目：0（蹄）、2（偶蹄，侧面看是一个开叉）、4 或 5 个趾垫；
- 爪长：0 到食蚁兽的长爪；
- 蹄：0–1，趾尖慢慢包成蹄。

一共 5 个控制量。典型形态：猫爪、兔的长后脚、熊掌、鼹鼠的铲子、鹿蹄、马蹄。

## 五、耳、角

- **耳**：已经做好，`ear.ts` 的 5 个量：耳长、耳宽、耳尖圆尖、软硬、位置。
- **角**：一根渐细的弧，控制量是：
  - 长；
  - 根宽；
  - 弯；
  - 弯曲往尖端加强的程度（对数螺旋）；
  - 渐细的快慢；
  - 再加离散的类型：额角左右一对、鼻角前后排、鹿角分叉。

## 六、拼成整只

- 零件之间只通过铆钉相连。拼法（谁挂在谁上、前后顺序、远侧调暗）沿用现在 `cutoutPuppet.ts` 的骨架和动作，不改动作那一套。
- 从设计到零件：设计台的参数（体重、腿长、颈长……）先算出身材（`plan.ts`），身材再给出每个零件的骨长和站点宽。典型形态是一组控制量的预设。
- **Lovart 的猫成品图怎么办**：
  - 它的纸纹、颜色、白边、铆钉的画法保留；
  - 它的零件形状变成"猫这个预设"的参照：猫的控制量就从成品图量出来，代码剪出来的猫要和成品图尽量一样。

## 七、步骤

1. **骨段拓扑和零件试验页** `parts.html`：每类零件一行，按预设排开，可以拖控制量。
2. 头的拓扑（第三节），和猫的成品图对比，量出猫的预设。
3. 腿和脚、躯干、尾，同样做一遍。
4. 整只纸偶切换到代码剪的零件。设计台留一个开关，可以和成品图版本对比。
5. 交给 Lovart：按拓扑设计每类零件的画法和变体（handoff/011 已经发了现状的截图）。
