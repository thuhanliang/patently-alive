# 游戏性诊断与设计原则（2026-10-24）

剪纸版试玩以后，用户的感受是"不好玩，像案例课件；听 GDD 的介绍想玩，打开却体会不到"。这份文档是之后几轮讨论的提炼：先诊断，再定边界，然后是设计原则和想法池。定下的结论已经写进 `GDD.md`（"愿景校准"的 2026-10-24 补充）、`DECISIONS.md` 和 `ROADMAP.md`，这里留完整的理由。

## 一、诊断

**一句话：玩家现在是审阅者，不是作者。** 推演写出结果，玩家点"确认"。课件把模型摆出来给你看；游戏把一个处境摆在你面前，模型只通过后果露面。

### 好玩是一层层叠起来的

| 层 | 时间尺度 | 是什么 | 试玩时 |
| --- | --- | --- | --- |
| 玩具 / 手感 | 秒 | 没有目标也想戳一戳，戳了立刻有回应 | 几乎没有 |
| 决定 | 分钟到天 | 一个有选项的处境 → 看得见的后果 → 下一个决定 | 几乎没有 |
| 故事 / 成长 | 季到年 | 客户、事务所、收藏、解锁、纪录片 | 一个三年后的分数 |

GDD 写的是第二、三层的骨架，第一层几乎没写，可玩家每一秒碰到的正是第一层。所以会"听着好玩，打开没感觉"。

### 截图里看到的

- **现场**：十几个"×2,770"之类的数量签，没有一个动作能对付两千多只鼠；缩放、俯仰、旋转三根滑块一直摆在屏幕上，像调试工具。
- **设计台**：十五个栏目和一列推导出来的数值。动物是一张不会动的小线稿，老同事的批注是"看着还行。投出去才知道。"它是一张表单，不是一门手艺。
- **季度结算**：第一年的恢复、稳定都是"—"，满意度 70 → 70，只有一个"继续"按钮。这一停既没有新东西，也不用做决定。
- **个案卡**：方向是对的（具体、有期限、有选择），但选择没有代价，卡片上还写着"个案不进评分"，开发者的注释漏到了界面上。
- **没有事务所**：游戏一打开就在现场。

### 从鸟岛数据里抽出来的通用规则

路线测试：种子 1，12 季，`scripts/routes.bench.ts`。

| 路线 | 最后的恢复分 | 备注 |
| --- | --- | --- |
| 不干预 | 42 | 稳定、多样性、花费、福利四项满分 |
| 只抓猫 | 32 | 比不干预还差；没有"回升一季" |
| 控鼠（网） | 54 | 三年移除 5,895 只鼠 |
| 小岛控鼠 | 70 | 第 9 季碰到过 96 |

1. **免费的信息会让"挣信息"的动作失去意义。** 死因页直接读引擎的全岛账本，开局就写着"巢失败（被船鼠吃掉）91%"。尸检本来要按齿距推理，答案却已经摆在旁边。
2. **分数要记得玩家做过的事。** 恢复分以"第一年同季"为基准，可第一年玩家已经在干预。第 5 季，控鼠路线的鸟比不干预多 25%（951 对 759），分数只高 8 分（52 对 44）。做对了，游戏却说"差不多"。
3. **转折要从推演里长出来，并用路线测试守住。** GDD 写的"抓猫 → 鸟回升一季 → 鼠兔反弹"没有出现：只抓猫从第一季起就比不干预差。
4. **玩家的力量要落在够得着的尺度上。** 一个笼一晚抓十只左右，对一万多只鼠等于没有，对一个十几个巢的巢区就看得见。做法是选好力量落在哪里，不是缩小地图（小地图已否决）。
5. **什么都不做不能拿高分。**
6. **玩家界面上不出现写给开发者的话。**

## 二、边界：为什么它必须是一个游戏

AI 工具擅长"想要什么就有什么"：图、故事、动作、视频。反过来也一样：什么都能发生，所以什么都不算数。不满意可以重新生成，结果可以商量，没有什么是挣来的，生物学可能是编的。

**游戏不可替代的，是一个不听你的、但讲道理的世界。** 只有可能的事才会发生，所以发生了的都算数。只有游戏给得了的乐趣：

1. **验收（主线）**：设计是假设，世界是实验。参照 Kerbal Space Program：自己造火箭，发射就是判决，炸了既好笑又有收获。GDD 的一句话"设计一种动物，看世界怎么验收它"说的就是这个。
2. **真相**：世界里有一个确定的答案可以挖。问 AI，它会直接告诉你，或者编一个给你。
3. **惊喜**：发生了没人写过的事，事后讲得通，而且能复现。
4. **精通**：越懂生物越会玩，知识就是技能。
5. **牵挂**：引种收不回来，死了不能重新生成，所以照料有分量。

由此得出：

- **约束是意义的来源**。Bernard Suits 说，玩就是自愿去克服不必要的障碍。但每条约束都要挣到自己的位置：要么带来一个有意思的选择，要么带来一个有分量的后果。两样都没有的就是摩擦。
- **铁律 5、6 就是游戏的身份**。一旦让 AI 决定结果，游戏就塌回了 AI 聊天工具。
- **和 AI 工具的分工**：AI 做的图、设定、传说可以当外观和名字进游戏（表达层，不影响能力）；游戏里真实发生过的事可以给 AI 当故事素材（以后通过 MCP 读出去）。什么是可能的、什么发生了，只由世界决定。
- **检验每个功能的一句话：交给 AI 聊天会不会做得更好？** 会，就不是游戏的核心（写传说、编一段舞）；不会，因为它需要世界的规则、真相和后果，就是核心（它熬不熬得过冬天，它为什么在发抖，它真实的家谱和命运）。

## 三、玩家

目标玩家的画像很具体：对生物和兽医有很深的兴趣，正在系统地学生物（课程对照见第七节），擅长和数据打交道，想象力丰富，喜欢编故事，养猫。

这些信息用来理解她这个玩家，**不是要硬塞进游戏的功能清单，不做大杂烩**。换算成游戏要有的品质：

- **真**：科学上诚实；
- **深**：想钻进去就有东西可钻；
- **有意义**：知识和关怀派得上用场；
- **有余地**：给她自己的创作留空间。

带个人色彩的东西只是点缀，由用户决定。

## 四、先做玩具

核心玩法是"玩具"，事务所是串联用的功能性设定，声音以后再做。顺序：

1. **设计台**：她的想象力进入游戏的地方。乐趣来自"真实的后果当场看得见"，不来自装扮选项的多少。
2. **世界**：放生、起名、跟随、观察。"看"之所以好玩，是因为玩家在参与创作故事，而不是看一个写好的剧本。
3. **诊台**：兽医的真实流程和工具。

然后再把它们串成一局（委托、事务所、审查、结算、战役）。

**做法**：

- 每个玩具先做成能单独戳着玩的页面，链接可以直接发给朋友。
- 每个交互先写一页手感说明：手在做什么，几秒内看到什么，哪里有惊喜。
- 验收看录屏，不只看截图。
- 试玩对目标玩家保密，由用户和朋友来试。
- 实现难度不预先设限，一步步来，每一步都能试玩。

## 五、呈现：会"演出自己生物学"的身体

设计台上的纸偶、现场的步态和体征、相机的照片、诊台上的症状、纪录片的定格，用的都是同一个身体。它演好了，设计出来的生物就有好效果，不靠预设动画。这是在 `creature-rig.md` 定的"动作够用就好"上往前走：

1. **节奏来自真实的缩放律**：步频 ∝ √(g/腿长)；Froude 数决定什么时候从走变成跑；呼吸和心跳 ∝ 体重^(−1/4)；尾巴、耳朵是弹簧跟随。每个设计自动动得不一样，而且是对的。
2. **体征长在身上**：胖瘦（体况评分）、喘、发抖、跛、伤疤、怀孕、老年的灰口鼻、没有牙。推演的状态和经历都变成看得见的样子。
3. **内容是行为加情境，不靠动画精度**：少量互动片段（潜近、追、逃、叼走、护崽、对峙）可以套在任意两个物种身上。演什么由推演决定，挑哪一段给玩家看由"导演"决定。
4. **静帧加运镜**：剪纸分层天然有视差，运镜像多层摄影机；配画面文字、旁白和特效。片子里的每个镜头都真的发生过。
5. **文字承担一半**，比如"它第三次在凌晨三点来到这个巢"。

**画面的任务是当证据，不是奇观。** 游戏里它瘸了，是因为骨头真的撑不住。

**有趣内容的公式：系统 × 情境 × 记忆**。导演检测值得一提的事（第一次、纪录、险情）；被命名的个体有家谱和伤疤；再加上手写的种子（个案、委托、历史卡）。

**美术素材**：先用代码画剪纸占位；需要正式素材时（零件表、诊台场景……）写需求，由用户生成。兽医部分的美术要下功夫，**不做成实验室模拟器**：交互落在动物身上，不落在仪表盘上。

## 六、打断与节拍

时钟保持实时（DECISIONS"节奏"），停在哪里要好好设计：

1. **只为两件事停**：一个有选项的决定，或者一个玩家正在等的答案。纯信息不停，它属于地图和笔记本。
2. **先留一个悬念**：布了笼、投了新设计、送了样本，时间流逝就是在等答案。"跳到下一件事"写清楚下一件事是什么，比如"跳到：明早收笼"。
3. **打断从世界里来，由人来说**：队员的对讲机、电话、来信。给 2–3 个一键就能回的答复，"不理它"也算一个。
4. **提前亮出威胁**（参照 Into the Breach），比如"巢区 B 今晚有鼠的脚印"。
5. **三级打断**：
   - **停**：有时限的决定；
   - **挂**：报告到了、队伍回来，放在边上的信件栏里；
   - **演**：只在世界里表演，不出界面。
6. **从世界里长出来的小目标**，比如"这窝蛋能不能孵出来？还有 21 天"。
7. **自检**：一个打断如果在一秒内就被点掉，它就不该存在。

参照：RimWorld 的实时 + 暂停 + 分派工作；Cultist Simulator 桌上倒计时的卡；RimWorld 的信件分级。

## 八、兽医：真实的流程和工具

- **流程**：信号与病史 → 体检（体温、心率、呼吸，黏膜颜色，毛细血管再充盈时间，体况评分，触诊，口腔）→ 问题列表 → 鉴别诊断 → 化验 → 治疗 → 复查。
- **访谈就是病史采集**：主人说不准，好兽医靠问对问题。
- **体征从推演的真实状态里渲染出来**，画在同一个身体上。
- **参考**：

| 层 | 参考 |
| --- | --- |
| 诊断 | Two Point Hospital 的"诊断确定度"；Project Hospital 的鉴别诊断 |
| 侦查 | Obra Dinn（三个一组确认）；Shadows of Doubt 的证据板；Papers, Please |
| 动手 | 触屏宠物医生游戏的听诊、触诊；RimWorld 治病时免疫和病情两根条的赛跑 |
| 群体 | Plague Inc: The Cure；Frostpunk 的艰难抉择 |
| 野外 | Alba；Pokémon Snap；Terra Nil |

## 九、想法池

这是一轮发散的结果，按用户的取舍标注。⭐ 是用户认可的重点；没有标 ⭐ 的先留着，以后一点点打磨。

### 设计台

- ⭐ **体型标尺**：动物身后叠一排同体重的真实动物剪影。
- ⭐ **投放前预测**：先猜能不能活、一年后有多少只，世界给出真实结果，攒成一份"你的预测和世界"的记录。
- ⭐ **一生快放**：30 秒看完一只个体的一生。
- **剖面 / X 光**。
- **能量小票**：每个部件每天花多少能量，打成一张小票。
- **极端设计的彩蛋**：100 吨的食草动物整天都在吃，1 克的恒温动物每小时都要吃。
- **和真动物合影**。
- **反向设计谜题**：拼出一只真的穿山甲。
- **两种现有技术之间渐变混合**，审查时查新颖性。
- **版本树**：v1 和 v2 逐项比较，对应召回改版。

### 世界

- ⭐ **认领起名**：起了名的个体一直存在，可以跟拍。
- ⭐ **家谱**。
- ⭐ **伪装相机、相册，加上习惯化**。照片和捕笼一样，从那一格的真实数量和事件里抽样，带种子、可复现；夜里是红外黑白照，眼睛反光。
- ⭐ **GPS 项圈**：走过的路用蓝图墨线画出来，圈出家域。
- ⭐ **标志重捕**：按重捕率估数，季末揭晓真数。
- ⭐ **"要是你没来"**：季末叠一条不干预的影子线，用确定性重跑得出。
- ⭐ **物种形成**：小岛种群分化，由玩家命名。
- ⭐ **演化开关**：设计在世界里慢慢漂移。
- **痕迹层**：脚印、粪便、啃痕，雨后变淡。
- **给地方起名**。
- **观察清单**。
- **食物网**：每条线上流过多少能量。
- **天气和季节成章**。
- **气候变化情景**。

### 节奏

- ⭐ **从世界里长出来的小目标**。
- 下面这些当小彩蛋：繁殖季成一幕、巢区、出诊板、委托是一桩案子、季中来电、年终年鉴。

### 兽医（用户认可，重点打磨）

- **体检手势**：按牙龈看毛细血管再充盈时间；跟着心跳点 15 秒算心率；摸肋骨打体况分。
- **化验台**：McMaster 虫卵计数（数完乘 50）、血涂片、读 PCR 电泳条带。
- **鉴别诊断板**：多查一项更确定，但动物也在恶化。
- **按体重算麻醉剂量**，手术时盯着呼吸。
- **复诊和临床记录**。
- **群体工作**：疫苗诱饵、FAMACHA 定向驱虫、耐药等位基因的频率。
- **收容、康复、放归**。
- **个案编辑器**。

### 故事

- ⭐ **剧场模式**：玩家挑演员（起过名的动物）、地点和情境，世界把它演出来。玩家来布景，推演决定结果。
- **故事书导出成绘本**。
- **以后：把一些场景做成可以打印、剪下来粘起来的真纸模型。**
- **跟一只动物过一天**。
- **传说和数据两种声音**。
- **旁白换口吻**。
- **MCP 故事钩子**：玩家自己的 AI 提出操作，玩家批准。

### 收集

- ⭐ **发现日志**：参照 Outer Wilds，成就是"第一次看到某件事"，不是分数。
- **专利证书墙**。
- **标本柜**。
- **档案馆一张张点亮**。

### 两个人

- ⭐ **甲方模式**：GDD 里已有的设计。一个人写藏着动机的委托，另一个人在事务所收到来信。
- **明信片**。
- **异步共用一个世界**（以后）。

### 画面

- ⭐ **多层剪纸的视差运镜**。
- ⭐ **默片式的剪纸字幕卡**（参照 Lotte Reiniger）。
- **按事件类型的镜头语言**。
- **红外和移轴**。
- **一天里的光线变化**。
- **出生和死亡的效果**：要温和。

### 底层

- ⭐ **回到案发现场**：确定性加快照，可以倒回去看。结案以后才开放，平时相机是看见过去的唯一窗口。
- **只挑选、不制造事件的导演**。
- **难度就是信息迷雾**：难度越低，免费给的信息越多。

### 不要（已写进 DECISIONS 的"已否决"）

- **每周挑战卡**；
- **平行世界对比**；
