# 纸艺标准件（2026-11-25）

用户：所有东西都要像"只用不同厚度的卡纸真能做出来"的模型——折、拼插、粘贴、卷纸筒和纸锥、厚纸板层层堆叠（内部可以掏空）。
重点不是曲面多，而是**轮廓、边缘、连接、堆叠**处理对：纸要有厚度，断面要有纸的纹理，交叉的地方一层压一层、不悬空、不穿模。
还要有五金件（钉、合页）、胶带、麻绳，动起来要像真的有分量。车、地形、植物、纸偶都复用这一套（`src/render/three/craft.ts`、`paper.ts`）。

## 纸材（模型毫米）

| 纸材 | 厚 | 用在 |
| --- | --- | --- |
| 薄纸 | 0.2 | 信、标签、胶带 |
| 卡纸 | 0.6 | 车身、补丁、植物、地形每一层 |
| 牛皮纸 | 0.4 | 口袋、帆布包、种子罐 |
| 金卡纸 | 0.5 | 所有"铜边"、框、徽章：正面有一点金属光，断面是白纸芯 |
| 毛毡 | 1.2 | 零件盘的底、坐垫 |
| 灰纸板 | 1.5 | 家具、木肋、箱子：厚的块是一层层灰纸板粘的，断面上看得见分层线 |

## 断面

断面的纹理坐标单独算：横跨正好一个纸厚，顺着边走。纹理上有压在一起的几层纸浆、两侧切口压实的暗线、顺着边的短纤维。
颜色是纸芯（比正面浅），覆膜纸（金卡纸）的纸芯是白的。剪纸植物的断面也一样。

## 做法

- **平板**（`slab`）：可以开洞；**纸条**（`strip`）：沿折线走、拐角斜切对接、平贴在底下那张纸上。
- **叠层块**（`cardBox`、`block`）：几层板粘成，最上和最下几层往里收（垫子、圆角）。
- **叠圈回转体**（`stackRound`）：水壶、碗、铃铛、瓶子、台灯底座——一圈圈纸的台阶，可以掏空。
- **卷筒 / 卷锥**（`rolled`）：杯子、笔筒、烟囱、灯罩、笔——看得见壁厚和一道接缝。
- **切片堆叠**（`slices`）：靴子这类有体积的东西，侧面轮廓切成一片片。
- **层次**：墙面 → 补丁和色带（一层卡纸）→ 金卡纸条（压在上面），每一层贴在下一层的表面上。

## 五金和辅材

开口铆钉（扁圆铜帽）、图钉、合页（两片铜片 + 轴，门和盖子真的绕着它转）、铜丝挂钩、纸胶带（半透明、两头撕开的锯齿）、麻绳（两股拧的，挂着按重力下垂）。

## 动起来

- 门、抽屉、盖子、方向盘：带阻尼的弹簧（`Spring`），到位时回弹一下，开到极限会顿住。
- 挂着的东西（铃铛、晾绳上的卡、帆布包、顶灯）：单摆（`Pendulum`），被碰了会按自己的摆长晃，慢慢停下；车一晃，所有挂着的一起晃。

## 2026-11-26 第二轮修正（用户：仍然光滑、没有边线、连接太整齐、抽屉像堆出来的、眼皮应该是卷帘）

参考了网上最简单的纸模（大众 T1 展开图、Westfalia 内饰）：它们的质感来自**印刷 + 折痕 + 描边**，不是几何有多复杂。

- **墨线**（`ink`）：每块纸的边、折痕勾一条深褐色细线；按"一起动的一组"合并成一个线网格。地形每一层的切口勾淡线。
- **印刷**（`printedPaper`）：车身墙面印上纸的斑驳、金边下的阴影、板缝双线、车尾百叶、驾驶室门缝、轮拱阴影、铅笔记号；灰蓝色带印上阴影和泥。
- **压边**（`bead`）：补丁、门、抽屉面四周一圈细细的凸棱。
- **盒子是折出来的**：`cardBox` 默认六面都是纸面（棱由墨线画），只有薄纸露断面；层层粘的厚块只在少数地方显式用。
- **不太整齐**：补丁的四个角各歪一两毫米。
- **眼皮是卷帘**：顶上一卷、十条纸板条、两边导轨、底下铜压杆；闭眼就是一条条放下来，卷随之变细。
- 小件：水壶改成卷筒 + 卷锥 + 圆盖。
- 下一步：照 Lovart 细节表（`handoff/010` 第 4 轮）继续复刻：窗帘、格子布坐垫、印刷木纹、合页的卷法、粘贴舌。

## 2026-11-26 部件实验台：一块一块对着效果图做（`lab.html`）

用户：离效果图差太多；像 SketchUp 草图；要一部分一部分精细做，每一块截效果图的局部、同角度对比，做到几乎一样再做下一块。还要"印刷 / 铅笔画"的色彩感。

**为什么像 SketchUp**（调研后的判断）：
1. 没有间接光、没有接触阴影——缝里、叠层下面不暗，暗部是平的；
2. 棱是锋利的直角，接不住光（效果图里每条棱都是圆的，有一条亮边）；
3. 一个面一个颜色，没有水彩的浓淡、纸面颗粒；
4. 墨线一样粗；光是正面打的，没有背光和天光的冷暖。

**这一版的画面管线**（`src/render/three/stage.ts`，以后车、岛、家都换成它）：
- N8AO 接触阴影（缝、叠层、贴地处自然暗下去）；
- 墨线：按深度找轮廓和折痕，近粗远细、有断续；
- 插画化（`look.ts` 的 ILLUSTRATE）：水彩晕开、色块交界处颜料沉积、纸面颗粒、暗部铅笔排线（更暗处交叉排线）、印刷色调；
- 光：太阳在后上方（效果图的影子朝镜头右下拉），朝镜头的面在背光里，只有偏暖的天光。
- 部件做法：`bev()` 倒角块——每块纸板的棱是圆的，接得住光。

**以后可以更进一步**：three-gpu-pathtracer（浏览器里路径追踪，静止的画面几秒收敛成真正的全局光照），要先把 three 升到 0.187+；M4 iPad 跑得动。

**进度**：
1. 车轮（`parts/wheel.ts`）：三排胎面砖、两圈胎侧砖、米色八角轮辋两层、深褐八角环、金色八角轮毂 + 八芒星。对比图 `art/incoming/refs/010-v2/lab-wheel-v6.png`。
2. 车鼻子正面（`parts/nose.ts`）：两只深灯筒的八角大灯（三层框、深铜内框、放射状暖黄灯玻璃、金色雨檐）、深凹的竖条格栅、凸出的方鼻头和金搭扣、两侧三根铜胡须、拼起来的厚纸板面板和补丁。对比图 `lab-nose-v6.png`。还差：雨檐做成折出来的帽檐、面板缺角和毛边、顶上的金边和铆钉。
3. 下一件：车头大灯（八角金框 + 小雨檐 + 放射状灯玻璃）→ 格栅和鼻头 → 挡风玻璃和卷帘 → 车身侧板 → 金边和铆钉 → 车顶护栏 → 篷子 → 车里。每件做完换进车里。

## 2026-11-26 怎么看设计图、怎么检查模型（从用户这几轮的意见里总结）

### 用户指出过的问题，和背后的原因

| 用户看到的 | 我当时为什么会做错 | 应该从设计图上看出什么 |
| --- | --- | --- |
| 车头、窗户、部件差距太大，像 SketchUp | 只拼了形状，没做光、倒角、纸的浓淡 | 设计图里每条棱都接光、缝里有暗、面上有浓淡和铅笔线：质感来自光和画法，不来自块数 |
| 车轮缝太大、分段比图上多 | 按"砖要小、要多"自己想了个数 | 数清楚图上一圈有几块、块有多大，比例照搬 |
| 斜面被拆成三段 | 不知道那一圈是什么，就当成平的一排排砖 | 看明暗：一圈比别处亮/暗的带子，是一个朝向不同的面（斜面），要做成一个面 |
| 中心和外圈之间奇怪的缝 | 每一圈各自按自己的半径、自己的分段做，接不上 | 设计图里看起来"自然"，是因为相邻的圈共用同一条边：内圈的内沿就是轮辋的边，接缝一条线贯通。做的时候要问"这一圈贴着谁、沿着谁的边" |
| 内圈 12 外圈 14 很奇怪 | 只顾了每圈的砖大小，没管和八角对不对得上 | 图上的接缝是从中心放射出去的、一路对齐的，说明大家用的是同一组角度。先看接缝怎么走，再定分段 |
| 轮毂凸出太多 | 为了"有层次"往外堆 | 看侧影和投影：设计图里轮辋几乎没有影子，说明它几乎是平的 |
| 表面闪烁 | 两个面在同一深度（轮辋板和深色环、砖的内侧和轮辋侧面）、画面颗粒每帧都变 | 每一层之间至少隔开一点；能动的画面里不能有每帧变化的噪点 |
| 轮毂图案太花哨 | 自己加了太阳纹、铆钉 | 放大看设计图：只有 8 瓣和一颗凸台。设计图没有的不加 |
| 白色八边形太小（我却去放大了中间的金星） | 理解成"中间那块"，没量 | 先量大块之间的比例（白八角高度占轮胎直径 0.62），再看小块；改哪一块先确认是哪一块 |
| 叠图看不清谁是谁 | 只用叠图 | 叠图看位置和比例，并排看细节和性格，放大的局部看小件；三种一起用 |

### 比例感（用户 2026-11-26："谁是谁的大概几倍，谁和谁差不多宽，长宽高在这个视角下还原出来是什么比例"）

动手前先写一张"比例表"，全用相对关系，不用绝对尺寸。车轮的例子：
- 白八角的高 ≈ 轮胎直径的 0.6；金色 ≈ 白八角宽的 0.4；深色环宽 ≈ 白边宽；
- 胎侧（白八角外沿到胎肩）≈ 白边宽的 1.5 倍；胎肩 ≈ 胎侧的一半；
- 轮胎厚（这个视角下看到的胎面宽）≈ 直径的 0.3。
车鼻子要写的：大灯外框宽 ≈ 格栅宽、≈ 方鼻头宽；灯筒伸出 ≈ 灯宽的 0.4；方鼻头伸出 ≈ 它自己的高；胡须 ≈ 灯宽的 1.2 倍……
做完后按同一张表逐条在截图上核对，差得多的先改。

### 每做一件，按这个顺序检查

1. **构造**：这东西如果用纸和铜真的做，会怎么做？几层、每层是什么形状、谁压着谁、谁贴着谁的边。相邻的层共用边，接缝要能"一路走通"。
2. **数量和比例**：数块数、量比例（占直径、占面宽多少），对着图照搬，不自己发明。
3. **起伏**：每一层凸出多少，看图上的侧影、投影和亮边判断。
4. **明暗和材质**：深浅交替、亮边、缝里的暗、颜色在它所处的光下是什么样（在影子里还是在阳光下）。
5. **简洁**：图上没有的装饰不加。
6. **渲染问题**：转几个角度看，有没有闪、穿模、缝里透光。
7. **三种对比**：叠图（位置、比例、镜头）、并排（细节、风格）、放大的局部（小件）。每一轮先列出差异清单，全部改完再看下一轮。

## 2026-11-26 做部件的方法（经验，每做一件都照这个来）

用户的批评："我不知道你是看不出来差异，还是觉得这样的程度就够好了"——并排看图时我会过早满意，比例差 10% 看不出来。

1. **先对镜头，再对形状。** 用叠图（`scripts` 里的 overlay：效果图的轮廓描成红线压在 3D 上，再出一张半透明叠图）把镜头的方向、远近、视角对准。车鼻子第一次就是镜头方向反了（效果图是从右上方往左下看的近等距视角），并排看根本看不出。
2. **先拆结构，再做细节。** 动手前先把效果图里这个部件"是怎么做的"写下来：有几圈、每圈几块、哪里是斜面、哪里贴平、谁压着谁。车轮的错误都在这一步：胎侧分段太多、斜面被拆成三段、轮辋和外圈之间多了一圈缝、轮辋凸出太多。
3. **每一轮先写差异清单，再改。** 像用户标注那样，一条一条写（"缝太大""斜面被分成三段""凸出太多""轮辋直径 0.48→0.41"），改完逐条核对。尺寸用比例量（占直径多少、占面宽多少），不靠感觉。
4. **颜色看所处的光。** 车轮在效果图里在车身的影子里，所以是深炭灰；在实验台上要给它同样的遮挡和光向，不然颜色永远调不对。
5. **控制轮数**：每件 3–5 轮，每轮改清单上的全部条目，而不是一次改一处。
6. **同心的几圈要用同一组角度。** 用户指出：车轮内外圈边数不一样（12、14）、和八角轮辋也不是整数倍，层与层之间就会出现怪缝。改成轮辋 8 边、外面每圈都是 16 段（和八角的顶点、边中点对齐），内圈的内沿正好贴着轮辋的边。凡是一圈套一圈的东西（灯框、窗框、轮子），边数要相同或成整数倍，折线对齐。
7. **凸出多少要量。** 效果图里轮辋几乎和胎侧平，只高出一张纸板；不要按"看起来有层次"去堆高。

### 车鼻子（第 2 件）学到的
用户的批评："叠在一起完全没有起到任何作用……哪哪都对不上，但是你自己好像没有任何意识。"

**错在哪里**
- 我只看了几个大东西的中心有没有落在差不多的位置，就说"基本重合"。
- 没有一处一处比形状、宽高比、伸出多少。半透明叠图糊成一片，我看不出来，也没有承认看不出来。

**现在的做法**
1. **量点，拟合，不靠目测。**
   - 在效果图上加 25 像素的网格放大看，标出十几个关键点：灯玻璃上下端、格栅上两角、方鼻头正面四角、背面角。
   - 把这些点和模型上对应的点一起交给最小二乘，同时求出镜头和比例（`scripts/lab/fit-nose.py`）。尺度用一个可信的长度定（灯玻璃的高）。
   - 平均误差几个像素，比例就可信。
   - 镜头定了以后，面板边、雨檐、胡须两端这些点，可以从画面反投到已知的平面上，直接读出尺寸。
   - 这一件拟合出来的结果和我目测的差很多：
     - 镜头离得远、视角很窄（fov 约 9°），几乎没有透视；
     - 灯是瘦高的八角（0.28 × 0.40），不是正八角；
     - 方鼻头只有 0.30 × 0.25；
     - 面板窄到灯框探出了面板边。
2. **轮廓叠图用两种颜色。** 效果图的边画红，模型的边画蓝（`scripts/lab/edges.py`）。哪里只有红、哪里只有蓝，一眼就能看到；比半透明叠图清楚得多。
   - 每一轮按部件逐个过一遍：外框、内框、顶边、侧面、伸出多少。
   - 说"对上了"之前，先写出哪些还没对上。
3. **先弄懂每块面是什么，再建模。** 我把灯筒右上方那块背光的斜侧面，当成了雨檐的"翼"，做出一个罩住灯的小屋顶。
   - 放大看，并想清楚光从哪来，才知道它是灯筒自己的面。
   - 雨檐其实只是一片平的帽檐。
4. **改一个量，要防止改过头。** 用户说雨檐偏小，我一次加大太多，结果比效果图还大。
   - 每次改完都要回到叠图上量，不按感觉加减。

**材质和颜色**
- **侧面不能比正面亮。** 纸板的侧面（厚度、倒角）要和正面同色、略深。
  - 我之前把侧面固定成了浅米色，方鼻头背光的侧面反而最亮。
- **"金"是印了金的卡纸，不是镜面铜。** 金属度高了，背光的面会发黑发褐。
- **格栅这类"条 + 缝"：** 缝要接近黑，条不能厚到斜着看就把缝挡住。
