# 工作室：游戏的家（2026-11-22）

用户 2026-11-22 的意见（原话摘要）：纸剧场和岛像两套独立的设计；纸剧场是一个孤立的盒子，还很粗糙。之前 Lovart 出过的工作台场景不错——整个工作台（室）就是一个可以交互的小场景。纸剧场可以是桌上的一个摆件，作为"地图"的入口，从中窥见一点局部，也能通过动效进入其中（全屏地图）。
用户还给了一张自己家书桌角落的照片，只为说明一种感觉：一个充满趣味和想象力的地方，每件小东西都能打开一个世界（不是魔法主题）。**不是参考对象**（见下面 2026-11-24 的修正）。

## 定下来的结构

- **工作室是游戏的家**：开场、委托之间、回来看看，都在这张桌前。没有菜单页面，菜单就是桌上的东西。
- **岛的纸雕摆件就是地图的入口**：它是这座岛按等高线切成的 A4 纸雕（和全屏地图是同一套纸，裁成一块、按 A4 缩小）。点它，镜头扎进去，停在和地图一样的位置，换成全屏的岛；退出时倒着飞回桌前。
- **原来的纸剧场盒子退役**（`diorama.html` 先留着作记录）。"从侧面看一带的近景"以后做成地图里推到最近时的视角，不再是另一个盒子。
- **做得出来**（用户：以后可以导出、打印、真的做成 A4 的桌面摆件）：纸雕的每一层同样厚（一张卡纸），层数不够就多叠；植物是立着的薄纸片；纸偶是铆钉连接的零件。游戏里的画面尽量是能真的做出来的样子。

## 2026-11-24 的修正

第一版工作室（`studio.html`）把那张照片里的东西几乎一件件搬了进来（青海波墙纸、框里的云、晶簇、天平、卡片抽屉……），做得又粗。用户："刻意且粗糙的模仿，既没有跳出我的真实场景，又做得很粗糙，思路完全被照片限制死了。"唯一被肯定的是"从桌上的岛扎进全屏地图"这个过渡。

所以：
- **只有一件事定了**：岛是这个地方里一件摸得着的实物（A4 纸雕），点它，镜头扎进去成为全屏地图；退出时倒着飞回来。
- **这个地方要承担的事**（不规定是什么东西）：收到求助、设计拼装一只动物、翻看前人的设计、看自己的专利、走进岛。
- **是什么地方、放什么东西，都还没定**。等 Lovart 的方向稿（`handoff/010` 第 1 轮，已重写：不发照片、不列家具，先要 8 个差别很大的方向）。
- `studio.html` 里现在的书桌、台灯、抽屉、天平等都是**临时的占位**，选定方向后整体重做，不在现在这一版上修修补补。
- 那张照片不进仓库、不发给 Lovart。

## 2026-11-24 第二个修正：先有存在的理由，再有样子

Lovart 第 1 轮的 8 个方向（`art/incoming/lovart/010/1-directions/`）好看也新奇，但用户指出：**它们的存在缺乏设定**，说不出为什么是这里、为什么是这个形式（例：列车——为什么是列车？）。

这个地方要满足的原则（也写进了 `handoff/010` 第 1c 轮）：
0. **想象力要有一个中心**：先发明一个小小的设定（一条世界规矩、一个秘密、一个习惯），家、岛、六件事都从它里面长出来，彼此说得通；不因为某个样子很酷就选它（用户："不能说因为飞船很酷，所以我就要做个飞船样子的。要考虑整个游戏。"）。
1. **可以有魔法**（用户 2026-11-24："不是一定要那么写实……从桌面的纸模到全屏地图，这不也像是一种魔法么。……想象力合理，能够为游戏整体和故事服务，而不是各个部分割裂的瞎想。……'岛''客户'都只是概念（甚至动物自己没准都能当客户）。始终记得这是一个游戏，而不是企业的科研工作平台。"）
2. 来回要顺：玩家在家和岛之间来回很多次；最好家和现场是同一个东西的两种状态（用户的想法：一个能开去各处的东西，到了就支起设计台、兽医台，地图里也看得见它）。
3. 会长大：做的事越多，痕迹越多。
4. 温暖、明亮、有人住、人的尺度；东西少而有意义。
5. 机关只是手势，不判结果（铁律：结果只由推演决定）。
6. 和岛同一种纸、看起来做得出来。

我先想的几种（给用户挑，不写进提示词）：
- **出诊的家**：事务所要上门售后，所以家本身会走；在路上是一间小工作间，到了岛上就支开成营地（设计桌、兽医台、晾纸偶的绳），地图里看得见它扎在岸边；去过的岛留下旗子、贴纸、回礼。
- **寄来的岛**：每份委托随信寄来客户土地的"扁平纸板套件"，玩家在桌上把它一层层立起来——这就是桌上那件纸雕的来历，也和"以后导出打印"同一件事；做过的岛一格格收在墙上，就是你的履历。
- **档案馆的楼上**：事务所租在自然档案馆的阁楼，翻前人的设计就是下楼；馆员是邻居，会在你的申请书页边写批注。
- **借住客户的地方**：没有固定的家，每份委托住进客户借给你的一间屋（看守屋、工棚、温室），旧东西装箱带走；温室、船舱这些样子就有了理由——它是某个客户的地方。

几种可以组合：比如"出诊的家" + "寄来的岛"。

## 2026-11-24 设计方案：事务所的车「勾勾」（待用户确认）

用户：货车、房车方向都不错，外观要有新意（像"会动的车"那类，不一定是猫），可以更华丽；请我直接给明确方案。

**一句话**：一辆圆头圆脑的老式厢式车，零件长成了一张温顺的脸；它就是事务所，开到哪座岛就在哪儿支开。它不是任何已有角色，五官全是车本身的零件。

### 外形
- **轮廓**：短车头、高圆顶的厢式车，前低后高，像一只伏着的大动物；车身奶油白配湖蓝的搪瓷漆，接缝处一道黄铜包边。
- **眼睛**：一对圆车灯，各配一片可以合上的黄铜眼皮。平时半闭，夜里亮暖黄的光。
- **嘴**：宽格栅是一张微笑的嘴，横着的黄铜格条；嘴角两侧各三根铜丝胡须。**信就从嘴里叼出来。**
- **耳朵**：两只后视镜做成叶片形，装在铰链上，会朝声音转。
- **头顶**：车顶行李架是一圈黄铜花丝的"冠"；冠上一只风向标——**形状是你最新一项专利的动物**（换了专利它就换）；旁边一根小烟囱，屋里烧水时冒出纸卷似的白烟。
- **身体**：侧面一块雕着动物浮雕的木板，放下来就是车外的折叠桌；一扇圆形彩色玻璃窗，颜色随车停的那座岛变；腰线上一条黄铜带，挂着**专利搪瓷徽章**，一项一枚。
- **尾巴**：后门打开，一面帆布遮阳篷像扇子一样展开（米白和湖蓝相间的条纹），这就是"支开"——也是这辆车最华丽的一刻。
- **脚**：轮毂像圆圆的脚掌（四个肉垫似的铆钉），挡泥皮像脚边的一撮毛。
- **铃铛**：保险杠下面挂一只小铜铃。

### 表情 = 游戏的反馈（不用看界面，看车就知道）
| 发生了什么 | 它的样子 |
| --- | --- |
| 待着 | 眼皮半闭，车身轻轻起伏（呼吸）；烟囱偶尔冒一缕 |
| 来信 | 耳朵一下转向前，眼睛睁圆，铃铛响，嘴里叼出一封信 |
| 拿到专利 | 腰线上"叮"地多一枚徽章，风向标换成新动物，篷子抖一下 |
| 岛上出事 | 风向标上升起一面朱红小旗（同一时间只有一处最响的警报） |
| 去岛上 | 后门打开、篷子展开，像打了个哈欠 |
| 从难搞的岛回来 | 身上带泥、多一块补丁，眼皮更沉 |

### 在地图里
走进岛以后，它小小地停在岸边：篷子展开、木板放下成桌、眼睛闭着在打盹。**点它就回家**——"回到桌前"不再是一个按钮，而是这辆车。

### 会长大
徽章越挂越多（挂满一条腰线就挂到车顶的冠上）；车身贴上去过的岛的贴纸；补丁、磨白的漆、换过颜色的零件。一年以后，车顶的冠上全是叮当响的徽章。

### 里面
就是第 1d 轮房车里面那张（`art/incoming/lovart/010/3-mobile/B1-caravan-inside.jpg`）的布局，搬进这辆车：门上的投信口改成"从嘴里叼进来的信落在门边的碟子里"。

## 2026-11-25 「勾勾」建成 3D（`van.html`、`studio.html`）

用户在 Lovart 改了几轮，定下纸模型版的设定图（`art/incoming/lovart/010/4-abao/`），要求照它做成精细的 3D。

- **全部由代码生成**（`src/render/three/van/`）：车身是一块块有厚度的卡纸（墙、倒角、车顶都是平板拼起来的，断面看得见），接缝包黄铜条、钉铆钉；颜色按设定图（奶油、桃色、灰蓝的拼贴纸，下半截一道灰蓝带子）。
  - 脸：八角车灯是眼睛（也是车里的前窗），黄铜眼皮往下拉就是闭眼；格栅是嘴，叼着一封信；六角小灯、铜丝胡须、鼻子、保险杠下一只铜铃；叶片形后视镜是耳朵。
  - 车顶：黄铜花丝的冠（每格一对涡卷）、小狗风向标、烟囱（会冒纸卷似的烟）、条纹篷布卷。
  - 侧面：八角花窗（八块彩色玻璃）、雕着小狗的木板（营地里放下来是桌子）、一排搪瓷专利徽章、八角的卡纸车轮和黄铜轮毂。车尾：两扇门、六角尾灯、踏板、一根带流苏的绳子尾巴。
  - 里面（剖开的娃娃屋）：工作台（灰蓝抽屉柜、木箱）、台面上的零件盘、铆钉碗、剪刀、尺、草图、笔筒、**装着这座岛的 A4 纸雕托盘**、黄铜台灯；抽屉墙（两只抽屉拉开，里面是前人的设计卡）；晾绳上一排专利卡；驾驶座、方向盘、仪表；工具挂袋、帆布包、绳卷、水壶和杯子的小搁板；出诊皮箱；门边一碟来信；靴子、铜水碗、泥爪印、条纹地毯、顶灯。
- **会动**：呼吸、眨眼、耳朵、风向标、烟、尾巴的流苏、专利卡轻晃、水壶的热气；"来信"时睁眼、竖耳朵、铃铛晃、信从嘴里探出来；营地时后门打开、雕花板放下、篷子展开。
- **家**（`studio.html`）：剖开的车厢就是家。鼠标停在东西上出纸签；点托盘里的岛，镜头扎进去换成全屏的岛；岛上，勾勾支着篷子停在南岸打盹，点它就倒着飞回车里。
- **外部模型**：查过 Poly Haven（CC0，有椅子、台灯、皮箱、水壶、靴子等），都是照片级的高模和照片贴图，放进纸模型会混搭，所以全部用代码按纸模型的做法做，只参照了这类物件的比例。
- **性能**：不会动的零件按材质合批（`bake.ts`），托盘里的小岛只留灌丛和树、不投影。家的画面每帧约 1100 次绘制、约 105 万个三角形（含两盏灯的阴影）。真机帧率待验证。
