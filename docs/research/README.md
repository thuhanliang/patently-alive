## 要点

1. **现在任何部件组合都能活，只看环境**，用户的判断对。唯一的"造不出来"是翅膀 + 超过 13 千克就悄悄不会飞
   （`src/sim/design.ts`）。
2. **原作里的失败几乎都对应一条可以按体重和部件算出来的真实约束**：头高 → 血压（长颈鹿）、
   消化方式 × 额外开销 → 钙不够（独角兽骨质疏松）、力重比（天马、迦楼罗）、尺寸（30 米 → 3 厘米）、
   去掉血红蛋白 → 要大心脏和冷水（冰鱼）、骨密度 ↔ 灵活性和呼吸（肋突螈）。只借这些生物学，不借原作设定。
3. **守住"提示，而不是禁止"**：不可行的身体照样能投放，在世界里按程度失败（跑不动 → 站不住、失温、难产……），
   尸检有清楚的死因，**试验田在投放前就让它看得见**。
4. **植被现在吃得掉、吃不坏**：有下限，每天最多啃下限以上的 5%，按 logistic 长回来。
   牧场科学的"残留量 + 根储备 + 土壤 + 退化态"可以让它被真正吃坏、几十年长不回来。
5. **生物防治的审批几乎就是我们申请书 → 试验田 → 审查意见的真实蓝本**：
   寄主范围试验（无选择 / 有选择 / 多代）、成功率基准（昆虫天敌约 1/3 定殖、1/10 管用）、
   著名失败的性状原因（獴食性宽跑出投放地、蔗蟾有毒、玫瑰蜗牛偏爱小猎物、黏液瘤放出去还在进化）。
6. **WHO 的分阶段试验路径**（实验室 → 封闭野外 → 分批开放 → 上市后监测）可以直接用来组织试验田和投放，
   加上"可逆性等级"（不育 / 自限的审查宽，会自己扩散的严）。

## 需要你定的事

1. **先做哪几类"活不成"**：骨骼、飞行（连续曲线）、体温、消化与食性、循环、繁殖。
   建议先做**骨骼、消化与食性、繁殖**：和现有槽位（腿、消化、嘴、育幼、窝仔数）直接对得上，
   不需要给世界加气温。体温要先给情景加气温，循环要先有脖子 / 身高部件，可以晚些。
2. **"更自由地捏"走哪条路**（`VIABILITY.md` 第六节）：
   (a) 外观自由、能力不变；或 (b) **功能性塑形**：把体重分给骨骼、肌肉、消化道、心血管、脂肪，
   这些份额正好是可行性检查的输入（建议 b，外观再叠加 a）。
3. **植被要不要改成能被吃坏**：会动阶段 1 的平衡，要重跑路线回归；可以先只加"残留量 + 根储备"。
4. **审批流程借多少**：WHO 四阶段、可逆性等级、寄主范围试验、"生态替代"这类专门申请。
5. **排在哪里**：插进阶段 3 第 5–7 步，还是在第 5 步前先加一段"阶段 3.5：身体可行性"。
