# 勾勾外观：审核记录（给独立审核员看的上下文）

每一轮审核前附上这份记录，说明之前提过什么、已经改了什么、哪些是有意不做的，避免重复提问题。

## 做法（不要再建议改回去的）

- **建模顺序**：先描三视图的侧面外轮廓，量正面截面，推出体块；再用布尔运算"雕刻"（轮拱、服务侧开口、舷窗凹槽、挡风玻璃窗洞、后门）；最后把体块的每个面变成一张整纸，再按设计图贴多层纸。
- **一个面一张整纸**：不切小块。早期切成随机小块，被用户否掉了（"像碎纸拼接"）。
- **颜色用多层纸**：色块是贴在整纸上的一层纸，有厚度。
- **金边不是套路**：只加在设计图里显眼的地方，比如腰线、窗框、轮眉、檐口上楣。不要建议每条棱都包金边。
- **不要碎纸条**：用户看了炸开图，觉得细碎的小件太多，已经合并成少数几块整形状。新加的东西必须是能叫出名字、有明确位置的零件。
- **服务侧开口**：切下来的墙就是两扇板。上扇往上翻，上面绷着遮阳篷；下扇往下放平，就是桌面。合上时补回一面整墙。
- **胡须**：用户不喜欢金属杆，已改成剪纸胡须，每侧三根细长的奶油色卡纸条，用一颗金扣插在信箱侧面。
- **后视镜**：镜面朝后，从侧面看只是一条窄边。
- **内部暂不做**：外观整体评审完后，再请 Lovart 出内部细节图。

## 第 r1 轮（2026-11-26）审核意见的处理

- **已改**：
  - 遮阳篷：横向条纹（沿车长每 0.15 米一条），外沿下斜到 63°，侧视落差约 0.3 米；
  - 信箱：伸出量 0.17 → 0.07，胡须跟着贴近正面；
  - 狐狸挡板：做成梯形斗（正面底边内收，两片侧板连回车身墙）；
  - 栏杆、风向标、扣件统一用金卡纸色；风向标立杆缩短，换成奔跑的狐狸侧影；
  - 后视镜：奶油色；
  - 轮胎：从近黑改成暖灰褐。
- **核实后不改**：
  - "车太扁、车轮太小、腰线以下太矮"：在同比例的侧视对比图上实测，车高（地面到车顶约 0.6 / 1.2 像素比一致）、轮径（约 0.84 米 ≈ 设计图）、腰线高度（1.35–1.44 米）都和设计图一致。审核员可能被黑色轮胎的视觉重量误导了，轮胎改浅色后再看。
  - "挡风玻璃太小"：在正视图上实测，设计图玻璃约 x ±0.72、高 0.42，模型一致。
  - "删掉大灯的金色遮檐"：新三视图里没有遮檐，但用户之前认可过这个设计（"斜面的翼是对的"），保留。
- **暂缓**：后门做薄单板 + 窗，放到车尾那一轮一起做。
