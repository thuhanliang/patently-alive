# 勾勾的部件清单：每一块是什么、做什么用、和谁连在一起

（2026-11-26。来源：三视图 `art/incoming/lovart/011/3-orthographic.png`，拆解图 `1-exploded-wheel-chassis.png`、`2-exploded-front.png`，整体效果图 `010/5-details/6-overall.jpg`。）

用户的要求：**每次画、每次建模之前，先想清楚它到底是什么东西**，不只描线段。
AI 画的几张图之间会有细微不一致，遇到时按"它是什么、怎么用"去判断，不硬照某一张。

建模顺序：先做大块，再一刀一刀"雕刻"出细节，最后读出几何体每个面的坐标，变成一张张卡纸部件。

## 一、大块（体块）

| 部件 | 是什么 | 做什么用 | 连接 |
|---|---|---|---|
| 车鼻子 | 车头最前面一块厚纸板，**整面是平的**，上面装两只大灯、格栅、信箱、胡须 | 勾勾的"脸" | 是引擎盖体块的前脸；灯、格栅、信箱都装在这个面上，不能伸到面外 |
| 引擎盖 | 鼻子后面一个**往后抬高**的盒子，顶面是斜的，中间有一块凸起 | 发动机舱 | 前接鼻子，后接驾驶室的窗台 |
| 驾驶室 | 有挡风玻璃、侧面一个大八角舷窗的盒子；侧墙比下半车身窄（正视里肩部收进去） | 开车的地方，也是勾勾的"眼睛"（玻璃后面是卷帘眼皮） | 前接引擎盖，后面和货箱是**一个连续的车身**，不是两个盒子 |
| 车顶 | 驾驶室和货箱上面一整块顶，两侧倒角；车尾那段（烟囱附近）略高 | 上面有栏杆、行李架、风向标、烟囱 | 盖住整个车身，前面有一道倒角接挡风玻璃上沿的顶梁 |
| 货箱 | 驾驶室后面的长盒子；**服务侧（+x）有一个大开口**，开口里是小工作室 | 勾勾的"店面" | 和驾驶室同一个车身；开口上面是遮阳篷，下面是桌板 |
| 车底盘 | 车身下面一层深色的底板，前后轮之间 | 承托车身、装车轴 | 轮子装在底盘的车轴上（拆解图：轴 → 垫圈 → 轴套 → 销） |

## 二、雕刻（从大块上挖掉的）

| 位置 | 是什么 | 注意 |
|---|---|---|
| 前后轮拱 | 车身侧面为轮子留的八角形缺口，边上有一圈米色厚边 + 金包边（拆解图里是带台阶的边框） | 只挖车身两侧，中间的底盘保留 |
| 服务侧开口 | 货箱 +x 侧的大窗口：上沿是遮阳篷的横梁，下沿是桌板；里面是工作室（搁架、抽屉、台灯） | 挖进车里，留下远侧墙、地板、车顶 |
| 舷窗 | 驾驶室侧面的正八边形窗，窗里有卷帘 | 浅浅凹进去，再装窗框 |
| 挡风玻璃 | 两片玻璃，玻璃后面是卷帘（眼皮） | 窗洞凹进去，再装玻璃框和顶梁 |
| 后门 | 车尾一扇门（三视图侧视里是打开的，后视里是关着的双开门）——判断：**是一扇向外打开的门**，铰链在服务侧那边 | 后墙上开门洞，门板挂在铰链上 |

## 三、装在体块上的部件（每一个都要交代怎么连）

| 部件 | 是什么 | 连接 |
|---|---|---|
| 大灯 ×2 | 正八边形的灯，金框、灰粉内框、灯玻璃，上面一片金帽檐 | 钉在鼻子正面上，**整只灯在面板里面** |
| 格栅 | 鼻子正中一扇竖条格栅 | 嵌在鼻子正面里 |
| 信箱 | 格栅下面凸出的小盒子（可以掀盖，拆解图里有铰链盖） | 粘在鼻子正面上 |
| 胡须 ×6 | 黄铜杆，猫胡须 | 根部插在鼻子侧边的小座上 |
| 保险杠 + 铃铛 | 鼻子下面一根横的厚板，两头包金角；中间吊一只铃 | 保险杠用金卡件固定在鼻子下沿；铃挂在保险杠下的吊环上 |
| 后视镜 ×2 | 长方形镜板 + 弯臂 | 弯臂根部钉在 A 柱外侧 |
| 车顶栏杆 | 一圈木栏杆，X 形交叉 | 立柱下有方座，粘在车顶上 |
| 风向标 | 车顶前部一只小狗剪影，立在一根杆上 | 杆插在栏杆前横杆上的座里 |
| 烟囱 | 车尾那段车顶上的小方筒 + 帽 | 底座粘在车顶上 |
| 遮阳篷 | 条纹布，前沿一排扇贝边，两根斜撑 | 后沿卷在开口上沿的横梁上；斜撑下端撑在车身侧面 |
| 旗帜 | 驾驶室和货箱侧面一排小三角旗，每面一只狗 | 挂在一根细金绳上，绳两端钉在车身上 |
| 桌板 + 狗挡板 | 开口下沿翻下来的一块板（翻开是桌面），下面挂一块印着狗的挡板 | 桌板用铰链挂在开口下沿；挡板挂在桌板外沿 |
| 坡道 | 车尾一块斜板，从后门口搭到地上 | 上端挂在后门槛上，下端落地 |
| 凳子 | 一张折叠凳 | 独立放在地上 |
| 尾灯 ×2 | 车尾两只六边形红灯 | 钉在后墙下部 |
| 车轮 ×4 | 外胎（一块块砖样的胎面）+ 八角轮毂 + 金色齿轮形的中心 | 轮毂插在车轴上，车轴穿过底盘 |
| 金包边、铆钉 | 每条棱、每条接缝上的金卡纸条 | 压在两张卡纸的接缝上，两端铆钉 |

## 四、不一致的地方（判断后的做法）

- **车尾的"台阶"**：侧视里车尾下沿看着像凹进去一块，其实是坡道挡住了车身。车身底边一直平到车尾。
- **后门**：侧视里是打开的单扇门，后视里是关着的双开门。按"打开的单扇门"做（店开着门营业），以后可以做成能开关。
- **挡风玻璃的高度**：正视里玻璃比侧视矮（顶梁挡住了上沿）。按侧视的位置做，顶梁压住玻璃上沿。
