> **边界**：`DECISIONS.md` 已否决"照搬《天国餐馆》/ Heaven's Design Team 的概念和用词"。这份文档只是调研；

## 二、逐集

各集对应的漫画章节见本节末尾。

### 案件 1

**订单 A："能吃到很高处叶子的动物"** [官方]
- 有三个方案：土屋的天马、水島的"乒乓球树"、海原的长脖子鹿（首長ジカ）。[1] 首長ジカ、乒乓球树海绵出场 [官方]
- **失败 · 力重比**：火口一直反对天马，因为没有足够扇动翅膀的肌肉。[2+]（fandom + 观众推文）
- **失败 · 重力**：水島的乒乓球树在陆地上撑不住自己的重量。[1]
- **失败 · 循环**：长脖子鹿的心脏把血送不上头，火口做了试做品演示，一做就倒。[1]；另有一份二手梗概写的是"送血到脑要很大的心脏，于是脑贫血"，没读到原文。
  - 初稿里"心脏得有 1.5 吨"的说法没找到出处，删除。
- **修正**：大家以最简单的海原方案为底稿改 → **长颈鹿**，获批。[1] 长颈鹿出场 [官方]。具体怎么改的（比如加长腿）：未核对。
- **意外获批**：乒乓球树后来以海绵的身份获批 → **乒乓球树海绵**（深海肉食海绵）。[1] 出场 [官方]
- 初稿说"长颈鹿缺蛋白质吃鸽子"：只在开播时的一条观众推文里看到"キリンはたまに、ハトを食べる"，像是原作宣传语，没法确认是剧情。删除。

**订单 B：蛇和鸟的军备竞赛**（不是神下的订单，是水島的蛇吃金森的鸟蛋惹出来的）[1]
- 下田和木村想到：蛋察觉到蛇就提前孵化。用在鸟蛋上试了，有缺陷。[1]
- 用到蛙卵上获批 → **红眼树蛙**：蛇来袭时，卵团里的蝌蚪立刻孵出、掉进水里逃走（木村的方案）。[1] 出场 [官方]
- 金森把鸟巢挂到树枝末端 → **织布鸟**；冲突升级后又做了专门猎蛇的 → **蛇鹫**（ヘビクイワシ）。[2+]（fandom + 观众推文）图鉴未列。
- 原作里蛇被安排成"马去掉腿"。[1]

**订单 C："一点一点吃东西的动物"（海原）** [1]
- 海原的**小食蚁兽**（ミナミコアリクイ）被木村惦记着要吃；它的威吓姿势很弱。[2+]（fandom + 日文维基）出场 [官方]
- **修正 · 被捕食**：海原临时加了防御，参照能完全卷成球的**犰狳**。[1] 出场 [官方]
- 火口从实验室拿出旧的试做品当参考，是巨大的**雕齿兽**，把木村踩扁了（木村后来没事）。[2+]（fandom + 日文维基）
- 食蚁兽和犰狳都获批。[1]

### 案件 2

**订单 A："可爱、但又不可爱的生物"（冥戸）** [官方]
- 冥戸先做了一种在水里寄生的生物；金森建议做小一点更可爱，下田建议找擅长缩小的虫部合作 → **铁线虫**。[2+]（fandom + 日文维基）出场 [官方]
- 接着做出更进一步的 → **考拉**。[1] 出场 [官方]
  - 片中列举的考拉特点（有毒的桉叶、幼崽吃母亲的软便获得肠道菌、叫声难听）：未核对。前两项是真实生物学。
- 开头还有冥戸的箭毒蛙：蝌蚪在小水洼里靠同类相食活下来。[1]

**订单 B："带着厉害武器的动物"（土屋的独角兽）** [1]——一串失败：
1. 试做品倒下：**骨质疏松**，长角要的钙供不上。[1]
2. 对照：木村的**美洲马鹿**（アメリカアカシカ）同样有这个问题，但它是反刍动物，能从食物里吸收更多养分，所以长得起大角。[1] 出场 [官方]
   - fandom 写的是"三个胃对一个胃"；真实的反刍动物是四室胃。片中原话未核对。
3. 火口建议把角装在牛身上，土屋不肯，非要马。[1]
4. 角改成**空心**，少用钙 → 还是倒下，这次是营养 / 能量不够维持那么大的角。[1]
5. 水島建议**降低脑的功能**来省能量 → 太笨，躲不开障碍，角戳穿门后折断。[1]
6. 角加神经、做得更有弹性 → 在试验岛上两只互相打架一起倒下，第三只角卡在树上。神毙掉。[1]
- **废品回收**：海原把折断的独角兽角装到自己的海洋哺乳动物上 → **独角鲸**。[1] 出场 [官方]

**订单 C：试验岛上的海洋生物**
- 海原的海豚、鲸类一口气做了很多种，都获批。[1]
- 海豚吃冥戸的乌贼，冥戸给乌贼加变色、三颗心脏、加速；海原给海豚加回声定位……最后冥戸把乌贼放大 → **大王乌贼**；海原把海豚放大成鲸，加上"声波攻击" → **抹香鲸**，赢了这一局。[2+]（fandom + 日文维基）抹香鲸出场 [官方]
- 土屋偷偷塞进去的水马（ケルピー）被毙，改着改着成了**海马**。[1]
- 图鉴里还有"海豹"（アザラシ）[官方]，剧情里的位置未核对。

### 案件 3

**订单 A："没有翅膀也能飞"** [官方]
- 下田在试验岛上"召唤"出**龙**：其实是金森和木村翻出来的水島年轻时被毙的设计。[2+]（fandom + 日文维基）龙出场 [官方]
- 金森、木村试着让龙飞起来：[2+]（fandom + 日文维基）
  1. 往龙身里灌气体，靠浮力（日文维基说是氢气）；
  2. 为了不让它飘走，把龙接到一只巨型公鸡的屁股上当尾巴；
  3. 让龙像蜥蜴尾巴一样能脱落。
- **失败 · 物理**：有东西飞过、产生静电，充气的龙**爆炸**。[2+]
- **最终**：水島拿出**飞蛇（トビヘビ）**，演示滑翔，获批。[2+] 出场 [官方]
  - "压扁身体当翼型、靠升力滑翔"是真实生物学，片中讲解细节未核对。
- 木村画在地上的星形，加上龙的一些特征 → **海星**。[2+] 出场 [官方]

**订单 B：ケンタ的涂鸦**
- 土屋设计的海马，标签被ケンタ涂改成"雄性怀孕"，团队顺着改：雌性把卵交给雄性，雄性孵。[1]
- 水島想做"合体生物"，顺手做出 → **管水母**（巨大的クダクラゲ）。[2+] 出场 [官方]
- 五种旧设计拼合成的怪物（像克苏鲁）被上田删除。[2+]
- 试做室里冒出一只巨型怪物：ケンタ画的涂鸦被神批了。神要求"想办法处理"。[2+]
- 要拿回涂鸦图纸，就用动物进试做室去取：[2+]（fandom + 日文维基）
  1. 把**大猩猩**放大 → **中暑**倒下；
  2. 加散热改造（光头、鸡冠……）→ 两条腿撑不住体重（日文维基说是骨折）；
  3. 改四足，去毛，散热板换到头两侧，加獠牙，再把鼻子加长当手用 → **大象**，获批。
  大猩猩、大象出场 [官方]。（日文维基还说曾想放大鼹鼠，被火口否决。[1]）
- 图纸上写着"30m"；下田发现"0"看起来像"C"，改读成 **3 cm**，神认可 → **怪诞虫（Hallucigenia）**，寒武纪化石动物。[2+] 出场 [官方]
- 图鉴还列了**鮟鱇**（冥戸设计，雄鱼寄生在雌鱼身上 [1]），本集里的位置未核对。[官方]

### 案件 4

**订单 A："想办法让马飞起来"（神指名金森）**——**客户不满意**的典型 [官方]
- 神说"随便你做"，然后一稿一稿说"感觉不对"，返工地狱。[官方]
- 第一稿：修好所有缺陷的天马 → 立刻被毙，神要"更跳出框框"。[1]
- 第二稿：骨架感的邪恶风 → 神说不必像马、可以小一点。[1]
- 第三稿：小小的童话风 → 神说其实喜欢第二稿，要"放射状"、颜色"低调"。[1]
- 第四稿：童话版加上邪恶版的特征；海原建议加回声定位，冥戸建议吸血（金森拒绝）→ **菊头蝠**，获批。[1] 出场 [官方]
- 金森忘了擦掉一对多余的乳头，已经批了，就留着给幼崽吸。[1]（真实生物学：菊头蝠有一对不泌乳的"假乳头"给幼崽抓握。）
- 图鉴这一段是"菊头蝠·锤头果蝠"（ウマヅラコウモリ，"马脸蝙蝠"）。[官方] 初稿说的"图鉴讲蝙蝠和马亲缘很近"：未核对。
- 顺带获批：海原的"没有腿也能跑"的方案 → 一种心形海胆。[1]

**订单 B："像宝石一样的鸟" + "会产宝石的鸟"（金森）** [1]
- 第一版：有欧泊一样的虹彩，身体很小好躲天敌 → **失败 · 能量与体温**：太小，维持不了自己，也调节不了体温。[1]
- 改吃高热量的**花蜜** → 太小，停不到花上。[1]
- 去虫部学蜜蜂翅膀的原理，改成**悬停**，能前后飞 → 火口担心它得不停地吃，夜里也一样。[1]
- 水島建议夜里像蛇一样降低代谢（真实的蜂鸟是夜间蛰伏）→ **蜂鸟**。[1] 出场 [官方]；图鉴有"结构色"一段 [官方]。
- "会产宝石的鸟"：水島的鸟吃**原石**，靠砂囊里的石头磨碎食物，几年后磨成宝石；为此去掉飞行，强化腿力。金森抢过去加羽毛时图纸飞到下田手上，神批了 → **鸵鸟**。[1] 出场 [官方]

**订单 C："有条纹的动物"** [1]
- 部长的条纹马：戴上"狮子视角"眼镜测试，伪装效果不成立 → 失败。[1] 狮子出场 [官方]
- 海原提出：黑白两色吸热不同，能产生气流帮助散热。[1]
- 海原另有订单"看起来像肉食的草食动物" → 住在高海拔雪地、不冬眠的熊 → **大熊猫**。[1] 出场 [官方]
- **失败 · 图纸混淆**：熊猫的图纸里混进了海星的图纸，熊猫像海星一样爬，撕下的毛块再生成新熊猫，满屋都是。[1] 图鉴里的"コロコロパンダ"大概就是它 [官方]（对应关系未核对）
- 土屋放出**采采蝇**让熊猫睡着；采采蝇专找条纹粗的熊猫，避开了人 → 发现条纹能防蝇 → 条纹马获批 → **斑马**。[1] 出场 [官方]
- 上田承认是她诅咒了采采蝇，被神发配到地狱（即"熊猫骚动"，下一集官方梗概提到）。[官方] / [1]

### 案件 5

**订单 A：地狱主题乐园的吉祥物（客户横田）** [官方]
- 横田自带草图，土屋担心地狱的环境和重力，横田说不成问题。[1] 初稿里的"15 米、三个头"：未核对。
- 分两组比赛：[1]
  - **A 组（土屋、海原、金森）→ 刻耳柏洛斯**：
    1. 多了两个头，**协调乱了**，摔倒；
    2. 想把脑放到别处、两个头当摆设 → 横田要每个头都能独立行动；
    3. 中间的头做主导 → 总想要更多吃的；
    4. 给它吃以外的爱好（音乐）→ 三个头口味不同，想分头走。
  - **B 组（木村、水島、冥戸）→ 有翅膀的三头鳄鱼**：鳄鱼本来就合群、能合作；嘴一直张着保持吓人的样子；冷血，闭园后就睡，到点也不醒着要吃。
- 地狱两个都买了，付双倍。[1] 刻耳柏洛斯、鳄鱼、三头鳄鱼出场 [官方]

**订单 B："不擅长游泳的动物"（海原的水獭类）** [1]（日文原话未核对）
- 先给它杂食；它更想吃木村带来的海鲜。顺带：木村的**龙虾**获批。[1]
- 在模拟冷海的水箱里测试：[1]
  - **保温**：冷水里要不停地吃 → 毛加强保温；
  - **睡眠**：吃太多、没时间上岸睡 → 它们自己用海带把身体缠住当被子；
  - 加了存食物的**皮囊**，改了**肾**来处理盐分。
- **失败 · 磨损**：试验岛上发现得了**牙周病** → 它自己从皮囊里拿出**石头**砸开贝壳 → **海獭**，获批。[1] 出场 [官方]
- 初稿说的"和同伴手拉手睡"：读到的来源里没有，删除（这是真实生物学）。

## 三、作品里反复出现的"评审规则"

1. **流程**：神下订单（常常含糊、自相矛盾）→ 天使传话 → 设计师出方案 → **火口做试做品，看能不能正常活动** → 神批准或毙掉。[官方] 采用时天使会突然喊"天啓！"[1]
2. **订单与可行性是两道关**：设计既要让客户满意，也要符合物理和生物学。部长想要天马，火口照样拒绝。[2+]
3. **返工**：被毙的设计退回设计师，改到神满意为止（案件 4 最极端）。[官方]
4. **试做测试**：用真的捕食者（狮子）、设计师自己的身体（木村）、模拟环境（试验岛加拉帕戈斯可以改气候和地貌 [2+]、模拟浴室、模拟稻田）、同事扮猎物（下田）。[1]
5. **时间加速器**：模拟整个种群好几代的结果，还能倒着用。[1]；设备本身 [官方]
6. **缩放**：虫部把设计缩小；30 米做不出来的，3 厘米可以；反过来，放大的大猩猩会中暑、骨折。[2+]
7. **废品回收**：独角兽的角 → 独角鲸；被毙的龙 → 海星的底子；被毙的迦楼罗 → 坐骑，后来改成琴鸟；做坏的卵鞘 → 玉螺卵环；旧草稿被神突然批了（乒乓球树海绵、肋突螈）。[1]
8. **第二个客户**：地狱社买不需要在地上活的幻想生物（刻耳柏洛斯、三头鳄、使魔），给"不可行"的设计一个去处。[1]；横田下订单 [官方]
9. **失败的去向**：化石动物（雕齿兽、怪诞虫、霸王龙）在片中出现；它们是不是"停产的设计"只是推测，没找到明确说法（未核对）。多数不可行的设计只是被毙、回收或卖给地狱。

## 四、失败分类

括号里是集数。来源等级见第二节。

| 类别 | 例子（集） | 约束 → 改法或结果 |
| --- | --- | --- |
| **物理 · 力重比 / 飞行** | 天马（1）、迦楼罗（12）、龙（3） | 飞行肌肉不够 → 毙；牙太重 → 去牙的琴鸟；气体浮力 → 静电爆炸 → 滑翔的飞蛇 |
| **物理 · 尺寸 / 缩放** | 30 米涂鸦（3）、放大的大猩猩（3）、乒乓球树（1） | 造不出 → 缩到 3 厘米；放大 → 中暑、两足撑不住 → 四足、加散热板 → 大象；陆地上撑不住体重 → 去深海 |
| **物理 · 光学** | 全透明的观察者（7） | 折射率必须和环境一致 → 只有水里行；眼睛必须吸光 → 接受看得见的眼球，或缩成单细胞 |
| **物理 · 声学** | 猫头鹰（7） | 脚步声 → 飞行；翅膀声 → 锯齿羽缘；耳朵晃 → 压平成面盘；左右耳错开高度 |
| **物理 · 骨骼** | 骨头武器（8）、独角兽的角（2） | 骨折 → 加密度、错开关节 → 灵活性下降、呼吸受压；角卡在门和树上 |
| **生理 · 循环** | 长脖子鹿（1）、冰鱼（7，未核对） | 血送不到头 → 改设计；透明需要去掉红色的血（真实生物学） |
| **生理 · 体温** | 大猩猩（3）、宝石鸟（4）、冰岛的鸟（9）、海獭（5）、骆驼（13） | 太大 → 中暑；太小 → 失温、能量不够 → 花蜜 + 夜间蛰伏；腿露在外 → 失温，蹲着藏腿；冷海 → 厚毛、不停地吃；出汗失水 → 椭圆红细胞存水 |
| **生理 · 矿物与营养预算** | 独角兽（2）、长肋骨（8） | 单胃吃草供不起角 → 骨质疏松，反刍的鹿可以；空心角 → 能量不够；肋骨太长 → 骨质疏松 → 去牙换喙（龟） |
| **生理 · 饮食、盐、磨损** | 海獭（5）、冰岛的鸟（9）、鸵鸟（4） | 盐负荷 → 改肾、从鼻腔排盐；牙周病 → 用石头；砂囊磨碎硬物 |
| **神经 / 行为** | 独角兽减脑（2）、刻耳柏洛斯（5）、食蚁兽（1） | 减脑省能量 → 太笨；三个头协调不了、胃口和兴趣不一 → 维护成本高；威吓太弱 → 犰狳式卷球 |
| **感知 / 伪装** | 乌贼、变色龙（7）、条纹马（4） | 一眼被看穿；变色随光线和情绪，不是融进背景；条纹不在狮子眼里隐形 → 结果是防蝇 |
| **繁殖 / 社会策略** | 火烈鸟（6）、企鹅（9）、蟹奴（9）、裸鼹鼠（10）、熊猫（9） | 要成群才繁殖；亲鸟绝食 vs 雏鸟绝食（都批了）；寄生虫劫持亲代照料；女王用自己的粪便"保健品"控制群体（真实生物学：化学信号压制其他雌性繁殖）；只养一只幼崽 |
| **生活史 / 生态** | 不死的动物（10） | 不衰老 → 小个体被吃、没有新世代、多样性不足挡不住病原体 → 灭绝；灯塔水母的再生循环是例外 |
| **性选择** | 狮子（12）、鹿（12） | 雄性做大 → 不灵活、装车轮 → 打猎出问题 → 改成鬃毛；树枝角 → 发情期出问题 → 简化 |
| **客户不满意** | 金森的飞马稿（4） | "感觉不对" → 四稿 → 蝙蝠 |
| **图纸混淆** | 熊猫 + 海星（4） | 无脑、会再生的熊猫泛滥 |
| **幻想，直接禁止** | 天马、独角兽、龙 | 永久毙掉；零件回收（角 → 独角鲸） |

## 五、对我们有用的部分（只借生物学，不借设定）

见 `VIABILITY.md`。简单说：

- 原作里的失败几乎都对应一条**真实、可以按体重和部件算出来**的约束：循环（头高 → 血压）、钙预算（角 / 骨 × 消化方式）、力重比（飞行）、体型和散热保温（大猩猩中暑、蜂鸟失温）、肾的盐负荷、光学、声学。
  这些正是我们"能力只能由性状推导"（铁律 5）该补上的那一层。
- 原作的"试做 → 测试 → 改"对应我们已有的试验田；"测试员"对应审查员和试验田报告，不需要新角色。
- 原作的"失败也很好看"和 GDD 原则"失败也值得看"一致：失败要有清楚、可以读懂的原因（尸检写"肋骨骨折"、"失温"、"中暑"、"难产"），而不是一句"活不成"。
- 不借：神、返工式的客户刁难、地狱社、时间加速器、图鉴小剧场。
