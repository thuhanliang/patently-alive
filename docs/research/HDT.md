# 《天地创造设计部》逐集整理：每个动物、每次失败

调研日期：2026-10-15。用途：参考原作里"设计 → 试做 → 失败 → 改设计"的过程，找出背后的真实生物学约束。

> **边界**：`DECISIONS.md` 已否决"照搬《天国餐馆》/ Heaven's Design Team 的概念和用词"。这份文档只是调研；
> 游戏里只借**失败背后的真实生物学**（循环、钙、力重比、散热……），不借神、地狱社、时间加速器、返工这些设定。

## 二、逐集

### 案件 1

**订单 A："能吃到很高处叶子的动物"**
- 海原的**长颈鹿（首长ジカ）**被选去试做。[2+]
- **失败 · 循环**：血送不上长脖子，头晕、抬不起脖子。火口估算要把血压到那么高，**心脏得有 1.5 吨**，不现实。[1]
- **修正**：重新配比脖子和**腿**的长度（腿长一些，脖子就不用那么长），并解决只吃叶子的营养问题 → **长颈鹿**。[1]
- **后续 · 营养**：长颈鹿缺蛋白质，吃了一只鸽子。片中说真实长颈鹿偶尔啃骨头、吃腐肉。[2+]
- **失败 · 力重比**：部长想做**天马**，火口拒绝：翅膀的肌肉相对体重太弱。天马是"万年ボツ"（永远被毙）。[2+]

**订单 B：卵与天敌**
- 红眼树蛙的卵：蛇咬住卵团时，蝌蚪会立刻孵出逃走（真实生物学如此）。[1]
- 各设计归谁（水岛的食卵蛇、金森的织布鸟和蛇鹫）：未核对。

**订单 C：小食蚁兽、犰狳、雕齿兽**
- 海原的小食蚁兽威吓姿势太弱，差点被吃 → **行为 / 被捕食**失败。[1]
- 参照能完全卷成球的犰狳做修正。[1]
- 火口把犰狳放大成巨型试做品（**雕齿兽**，真实的已灭绝动物），把木村压扁了。[2+]
  作品暗示化石动物是"试做品 / 停产设计"。

**其他**：深海肉食海绵"乒乓球树海绵"出现在图鉴里，剧情不详。[1]

### 案件 2

**订单 A："可爱、但又不可爱的动物"（冥土）**
- 结果是**考拉**：主食是有毒的桉叶；幼崽吃母亲的粪便获得肠道菌；"死亡金属"一样的叫声。[2+]
- 中间版本（水生寄生虫、和昆虫部合作做铁线虫）：来源可能串了，**未核对**。

**订单 B："帅气的动物"（角）**
- **失败 · 矿物预算**：部长的**独角兽**屡次失败——
  - 长角要的钙，吃草的**单胃**供不上，试做品**骨质疏松**、累垮；[2+]
  - 角还会卡在树上；
  - 改成空心、更有弹性，维持起来还是太耗能。[2+]
- **对照**：鹿、马鹿是**四个胃的反刍动物**，吸收得够，长得起（还每年换）大角。[2+]
- **废品回收**：海原把**折断的独角兽角**装到自己的海洋哺乳动物上 → **独角鲸**（那支"角"其实是牙）。[2+]

**订单 C**：海原把海豚放大 → **抹香鲸**（深潜、和大王乌贼搏斗）。[1]

### 案件 3

**订单 A："没有翅膀也能飞"**
- 召唤一条**龙**做参考，试了几种让它飞的办法：[1]
  1. 灌气体，靠浮力；
  2. 绑在巨型公鸡上；
  3. 像蜥蜴尾巴一样能脱落。
- **失败 · 物理**：快速运动产生静电，充气的龙**爆炸**，本质上不稳定、易燃。[1]
- **最终**：水岛叫大家放弃龙，拿出**飞蛇（トビヘビ）**：身体压扁成翼型，像机翼一样靠升力滑翔。[2+]
- 观后感的一句总结："生き物は物理制約厳しいのね"（生物受的物理约束真严）。[1]

**海星**：木村在地上画的星星，借了龙的一些特征 → 海星。[1]

**订单 B：肯太（部长孙子）的涂鸦**
- 涂鸦早就被神批了，但设计图上只写着"30m"：一条 30 米、多足带刺的长虫。[2+]
- **失败 · 尺寸**：这么大造不出来。
- **修正**：下田发现"0"看起来像"C"，改读成 **3 cm**，神批准 → **怪诞虫（Hallucigenia）**，寒武纪化石。[2+]
- 还需要一个大动物，阴差阳错做出了**大象**。[2+] 鼻子、耳朵怎么设计的：未核对。

### 案件 4

**订单 A："想办法让马飞起来"（金森）**——**客户不满意**的典型
- 神说"随便你做"，然后一稿一稿说"なんか違う"（感觉不对），返工地狱。[2+]
- 第一稿被毙；神又说不必像马、可以小一点；第三稿精灵风也被毙，因为神其实喜欢之前邪恶风那版，还要"放射状"、颜色"低调"。[1]
- **结果**：**菊头蝠**。图鉴里讲**蝙蝠和马亲缘很近**。[2+]

**订单 B："像宝石一样的鸟"**
- 水岛帮金森 → **蜂鸟**（图鉴：夜里进入蛰伏状态）。[2+]
- "会做宝石的鸟" → **鸵鸟**（大概是蛋），细节未核对。[1]

**订单 C："有条纹的动物"**
- 部长参考老虎条纹的伪装 → **斑马**，配一只狮子当天敌。[2+]
- 熊猫一段剧情（黑白动物、"熊猫骚动"）来源串得厉害，不展开。

### 案件 5

**订单 A：地狱主题乐园的吉祥物（客户横田）**
- 要求：15 米、三个头。分两组：[2+]
  - **狼组 → 刻耳柏洛斯**：三个头意见总不一致，**行为 / 协调问题**，维护成本高；
  - **鳄鱼组 → 有翅膀的三头鳄**：三个头意见基本一致，好养。
- 地狱的订单不受地上生存规则约束（这类幻想生物只去地狱）。[1]

**订单 B：不太适应海洋的动物 → 海獭**
- **生理 · 盐负荷**：吃海鲜盐分多 → 加强**肾**。[1]
- **行为**：浮在水面仰睡，和同伴手拉手免得漂散。[2+]
- **保温**：在冷海里靠浓密的毛。[1]
- **失败 · 磨损**：咬硬壳伤牙（牙周病）→ 用**石头**当工具。[1]

### 案件 6

- 加拉帕戈斯的"命案"：水岛满身"血"。真相是**火烈鸟的嗉囊乳**（红色），对应金森的订单"**雄性也能哺乳的动物**"——火烈鸟雌雄都会分泌。[2+]
- 冥土偷偷把**鲨鱼**（双髻鲨、锯鲨）放进海里。[1]
- 漫画里有"草稿和定稿叠在一起，误合成一个设计"的桥段。[1]

### 案件 7

**订单 A："看起来没人、其实在那里看着的动物"**——一串失败：
1. 冥土以前的**乌贼**：一眼就被看出来（色素细胞变色，但融不进背景）。**感知**失败。[1]
2. **变色龙**：**变色太慢**（而且是随光线和情绪变，不是故意的）。[1]
3. **完全透明**（连眼睛也透明）：水岛指出**眼睛必须吸收光才能看见东西**，全透明就瞎了。**光学**限制。[2+]
4. **水里的透明鱼 → 冰鱼**：
   - 血红蛋白是红的，会暴露 → **去掉血红蛋白**，靠血浆溶解的氧；
   - 代价：**更大的心脏、更粗的血管**，**只能在冷而富氧的水里**活；[2+]
   - 剩下的问题：眼球还是看得见。[1]

**订单 B：夜里的观察者**
- 冥土的夜行试做品和部长的几乎一样，原来都是肯太画的 → **菲律宾眼镜猴**。[2+]
- **仓鸮、雕鸮**也出场；不对称耳朵等细节未核对。

### 案件 8

**订单 A："把骨头当武器的动物"（木村拿自己当试验品）**——一串失败：
1. 肋骨戳出来当武器。冥土牵来**狮子**测试，**骨头被折断**。[1]
2. 修正：**加骨密度、错开关节**，牺牲一点灵活性。挺住了，但挪了位置的肋骨压迫呼吸，木村**缺氧**倒下。**物理 / 呼吸**取舍。[2+]
3. 再把肋骨加长：钙的需求太大 → **骨质疏松**。考虑把牙齿的钙挪给肋骨。[1]
4. 观众的总结："骨の位置を変えるのは難しい"（改骨头位置很难）。[1]
- **最终**：**欧非肋突螈**——转动肋骨，让尖端刺穿自己的皮肤，常带着皮肤毒。[2+]

**订单 B：求偶竞争（说唱对决）**
- **冠海豹**：鼓起鼻囊，从鼻孔吹出红色气球。[1]
- 冥土的**挥足蛙（Staurois）**：用踢腿展示。[1]

### 案件 9

**订单 A："激发母性本能的动物"**
- **麻雀**："爱"常常是生存策略：叫同伴来一起吃，群体觅食更不容易被吃掉。[1]
- 冥土：一个毛茸茸、由**父亲**抱着的卵囊，其实是**寄生虫的卵**，扎根到宿主身上、骗它的神经系统当成自己的孩子 → **蟹奴（Sacculina）**：真实情况是让螃蟹去势、"雌化"去孵寄生虫。[2+]

**订单 B："住在冰岛上的鸟"**
- 木村的鸟腿长，被指出在冷地方腿长不好；海原的鸟看起来腿短，其实**腿很长、蹲着保暖**。[1]
- **两个都批了**：海原的是亲鸟绝食 → **王企鹅**；木村的是雏鸟绝食 → **帝企鹅**。[1]

### 案件 10

**订单 A："建立完美社会的动物"**
- 下田误入一个女王统治的地下王国，看似乌托邦，实际靠下药和操控维持秩序 → 模拟**裸鼹鼠**群落。[2+]
- 要点：以亲缘为基础、个体为群体服务（像蜜蜂、白蚁）；地下生活带来长寿和抗病。[2+]
- 女王用化学信号抑制其他雌性繁殖：真实生物学，片中是否讲到未核对。

**订单 B：返老还童与不死**
- 部长把时间加速器反着用在缩小的马上，变成了水母一样的东西；加上**再生循环** → **灯塔水母**。[2+]
- **关键的生态论证（反对不死）**：如果动物不衰老，被捕食的就是年轻、弱小的个体，世代无法更替，**这一支会灭绝**；衰老和世代交替是必要的。[1]
- 观众指出灯塔水母不是真的"变年轻"，是退回水螅体阶段。[1]

### 案件 11

- 时间加速器爆炸，众人变小，被吹到加拉帕戈斯（正设为丛林，冥土在那里实测**食人鱼**）。[2+]
- **素食的银板鱼（Metynnis）**：长得像肉食的亲戚，天敌就不敢惹。**防御性拟态**。[2+]
- 真实的食人鱼远没有传说中凶，主要啃别的鱼会长回来的鳍。[1]
- 木婆薯：生吃有毒（木村吃了皱眉）。[1]
- 地狱订单："口袋大小的使魔" → **兔子**。要点：**兔子吃自己的粪**（盲肠便），让难消化的植物再过一遍肠子。[2+]

### 案件 12

**订单："能用在地狱游乐设施里、也能送到地上的动物"（还要能吓到天使）**
- **迦楼罗（失败的前身）**：
  - 金森为地狱做成了耐火的；
  - **失败 · 力重比**：**牙齿让头太重，飞不起来**（鸟没有牙正是为了减重），一直掉进自己的火里；
  - 神很喜欢，留下来当**坐骑**。[1]
- **修正**：去掉牙齿就能飞，再加上**模仿任何声音**的能力 → **华丽琴鸟**。[1]
- "吓天使"的试作：冥土的**奇异多指节蟾**（蝌蚪比成蛙大得多）、部长的**霸王龙**。[1]
- 结尾：落在下田头上的草图，原来是下田自己的设计草稿。[2+]

### 特别篇（案件 13，Amazon 独占）

- 订单："做五种动物，再做一个把五种合起来的"。[2+]
- 五个子订单：沉不下去的；能吞针的；不怕扎脚的；耐极热也耐极寒的；少喝水也能活的。[1]
- 出场：**几维鸟**、**骆驼**。最后合体是不是骆驼：未核对。

### 动画之后的漫画（只找到零星）

- 冥土的**曼德拉草**：和独角兽一样是不可行的幻想设计。[1]
- "喝醉的泰迪熊"被毙，留作别的设计的底子。[1]
- 第 8 卷：老虎机式头脑风暴，随机组合全是废品。[1]
- 用户提到的鸭嘴兽、美西螈、树懒：没找到出场记录，不要默认原作里有。

## 三、作品里反复出现的"评审规则"

1. **流程**：神下订单（常常含糊、自相矛盾）→ 下田传话 → 设计师出方案 → **火口做试做品，测能不能在地上活下去、繁衍** → 神批准或毙掉。[2+]
2. **订单与可行性是两道关**：设计既要让客户满意，也要符合物理和生物学。部长想要天马，火口照样拒绝。[2+]
3. **返工**：被毙的设计退回设计师，改到神满意为止（案件 4 最极端）。[2+]
4. **试做测试**：用真的捕食者（狮子）、设计师自己的身体（木村）、模拟环境（加拉帕戈斯试验场、草原房间）。[2+]
5. **时间加速器**：模拟长期或整个生命周期的结果，还能倒着用。[2+]
6. **缩放**：昆虫部把设计缩小；30 米做不出来的，3 厘米可以。[2+]
7. **废品回收**：独角兽的角 → 独角鲸；旧草稿被翻出来（怪诞虫）；被毙的迦楼罗留作坐骑。[2+]
8. **第二个客户**：地狱社买不需要在地上活的幻想生物，给"不可行"的设计一个去处。[2+]
9. **失败的去向**：化石动物（雕齿兽、怪诞虫、霸王龙）暗示是停产的设计；但没找到"神让它灭绝"的明确规则（未核对）。多数不可行的设计只是被毙、回收或卖给地狱。

## 四、失败分类

| 类别 | 例子（集） | 约束 → 改法或结果 |
| --- | --- | --- |
| **物理 · 力重比 / 飞行** | 天马（1）、迦楼罗（12）、龙（3） | 肌肉相对体重太弱 → 毙；牙太重 → 去牙的琴鸟；气体浮力 → 爆炸 → 滑翔的飞蛇 |
| **物理 · 尺寸 / 缩放** | 30 米涂鸦（3）；放大的雕齿兽（1） | 造不出 → 缩到 3 厘米 |
| **物理 · 光学** | 全透明的观察者（7） | 眼睛必须吸光 → 接受看得见的眼球 |
| **物理 · 骨骼** | 骨头武器（8） | 骨折 → 加密度、错开关节 → 灵活性下降、呼吸受压 |

## 五、对我们有用的部分（只借生物学，不借设定）

见 `VIABILITY.md`。简单说：

- 原作里的失败几乎都对应一条**真实、可以按体重和部件算出来**的约束：循环（头高 → 血压）、钙预算（角 / 骨 × 消化方式）、力重比（飞行）、散热和保温、肾的盐负荷、光学。
  这些正是我们"能力只能由性状推导"（铁律 5）该补上的那一层。
- 原作的"试做 → 测试 → 改"对应我们已有的试验田；"测试员"对应审查员和试验田报告，不需要新角色。
- 原作的"失败也很好看"和 GDD 原则"失败也值得看"一致：失败要有清楚、可以读懂的原因（尸检写"肋骨骨折"、"失温"、"难产"），而不是一句"活不成"。
- 不借：神、返工式的客户刁难、地狱社、时间加速器、图鉴小剧场。
