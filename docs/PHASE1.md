# 阶段 1：野猫与鸟岛

## 目标

做出第一个情景"野猫与鸟岛"（参照新西兰 Predator Free 2050），以及管理员身份能用的兽医工具和个体视图（捕捉、检查、尸检）。
画面从这个阶段起开始换成田野笔记（见下面"美术"一节）。

## 关卡标准

**没人解释，试玩的人也能玩懂。** 过了才进入阶段 2（档案馆与引种）。

## 范围

做：

1. **地形与情景**：陆地（草地）、灌丛、海岸、水。一座主岛加几座离岸小岛，按情景数据带种子生成。
   情景数据写明地形参数、预设物种和开局分布、历史卡、业主目标、预算、人手。
2. **物种**：地面筑巢的本地鸟（参照新西兰的双斑鸻 / 斑鸻，*Charadrius bicinctus*）、野猫、船鼠、兔；植被和灌丛覆盖。
   - **巢**：鸟的蛋和雏鸟是幼体的头一段，留在巢里、不能逃，暴露程度由灌丛掩护决定。
   - **杂食**：食性写成比例（植物 / 脊椎动物 / 无脊椎动物），口径参照 EltonTraits。鼠以植物为主，顺带吃蛋和雏鸟。
   - **灌丛掩护**：草不够吃时兔子啃灌丛；灌丛长得慢，掩护下降，巢更容易被发现。
   - 谁吃谁仍然只由性状推导：体型、活动时段、会不会飞走（成鸟受惊会飞走，蛋和雏鸟不会）。
3. **死因记账**：每一笔死亡记死因（被谁捕食 / 巢失败 / 饿死 / 其他 / 人为移除）、格子和日期，按格子汇总。
4. **资源**：预算、人手（兽医队）、时间、满意度。每个操作声明花费，统一操作接口校验和扣除。
5. **兽医工具（第一批）**：诱捕（方形，按性状决定抓到谁，非目标物种也会进笼）、体检与采样（圆圈）、
   尸检（要有新鲜尸体）、移除（扑杀，降低满意度）、围栏（画线，阻断扩散）。
6. **个体视图**：检查卡（体重、体况、年龄估计、胃内容物）；尸检报告用临床口吻、按模板拼出；
   抽样推断"已采样 n 只，置信区间……"。
7. **观察层**：一次只开一个数据图层；同一时间只有一处最响的朱红警报；全图 / 区域 / 地块三档缩放。
8. **评价与流程**：开局读历史卡 → 推演 → 季度结算 → 情景结束的总结页。多维评分（目标物种恢复、稳定度、多样性、花费、福利），
   公式只在引擎里定义（铁律 4）。
9. **工程**：推演移进 Web Worker；存档 / 读档（种子 + 操作日志）；128×128 的地图上展开数百只个体保持流畅。
10. **平衡**：验证 GDD 写的转折——只清猫 → 鼠和兔反弹 → 尸检报告从"被捕食"变成"巢失败"；至少两条可行路线跑得通。

11. **美术（本阶段这部分）**：
    - 我用代码做：纸色底和配色表；地形的水彩感着色（水、海岸、草地、灌丛，植被多少表现为浓淡）；
      没有精灵时的动物占位（物种主色平涂 + 墨线轮廓的小形状，鸟白身黑帽）；蓝图蓝的工具批注
      （陷阱方形、采样圆圈、围栏线）；朱红警报横幅；种群曲线用物种主色；界面按钮和面板换成纸与墨。
    - 你来生成（`handoff/002`，本阶段要用）：四种动物和巢的精灵表、四种地形贴图（草地、灌丛、海岸、浅水 / 深水）。
      放进 `art/incoming/` 后我切图接入；没到之前用上面的占位，到了就替换，不用等阶段结束。

不做：引种和档案馆（阶段 2）、设计台和专利（阶段 3）、疾病、疫苗、驱虫、TNR（阶段 4）、纪录片、美术、多人、AI、MCP。

## 建议顺序（每步一个 PR）

1. 地形与情景数据：情景 schema、海岛生成、水域不可通行
2. 鸟岛物种：鸟、猫、鼠、兔；巢、杂食、灌丛掩护
3. 死因记账
4. 资源与操作花费
5. 兽医工具第一批
6. 个体视图：检查卡、尸检报告、抽样推断
7. 观察层与警报、三档缩放
8. 评价与流程：历史卡、季度结算、总结页
9. Web Worker、存档读档、性能
10. 调平衡、验证转折、发 Pages 版本（阶段末，等试玩判断）

其中美术不单独排一步：配色和地形着色随第 1 步，动物占位随第 2 步，批注随第 5 步，警报随第 7 步；精灵和贴图到了就接。
