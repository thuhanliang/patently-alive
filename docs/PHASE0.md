# 阶段 0：灰盒推演

## 目标

做一个只用灰色方块的生态推演：一片草原，3–4 个预设物种，能看到种群曲线起伏。验证推演本身好不好看，其余一概不做。

## 关卡标准

**我自己看得停不下来。** 过了才进入阶段 1（野猫与鸟岛）。

## 范围

做：

1. **项目骨架**：TypeScript + Vite + PixiJS + Vitest + zod，按 CLAUDE.md 的目录结构。
2. **地图**：一块格子地图（先 128×128 左右，代码上不限制尺寸），每格有植被量，按季节生长。
3. **物种（数据文件）**：草、食草动物（如兔）、小型捕食者（如鼬或猫）、可选一种杂食或第二种食草动物。参数包括体型、食性、繁殖、寿命、扩散；尽量用真实数量级。
4. **推演**：
   - 远处每格存数量（可按年龄段/状态分组）；
   - 镜头拉近的区域展开成个体，个体各自移动、进食、繁殖、死亡；
   - 离开视野时收拢回格子数量；**展开收拢守恒**。
   - 固定步长、带种子随机数，结果确定。
5. **画面**：格子按植被量着色；动物用不同灰度的方块/圆点；平移和缩放（至少两档：全图 / 地块）。
6. **种群曲线**：每个物种一条线，可以暂停、加速、单步。
7. **操作接口雏形**：先只有"开始/暂停/调速/改种子/投放 N 只某物种"，但已经走统一操作接口、写操作日志。
8. **测试**：
   - 同种子 + 同操作日志跑两次，结果逐位相同；
   - 展开再收拢，数量和状态守恒；
   - 一个简单的平衡回归：默认参数下跑 N 年，没有物种在头几年就灭绝或爆炸到上限（只做报警，不做硬性要求）。

不做：美术、界面装饰、疾病、兽医工具、设计台、专利、多人、AI、MCP、纪录片。

## 建议顺序（每步一个 PR）

1. 骨架 + 带种子随机数 + 固定步长循环 + 确定性测试
2. 格子地图和植被生长 + 灰盒渲染 + 平移缩放
3. 物种数据 schema + 按格子的数量推演 + 种群曲线
4. 近处展开成个体 + 守恒测试
5. 操作接口和操作日志 + "投放"操作
6. 调参数、补平衡回归测试，导出一个可以在浏览器打开的版本（GitHub Pages）
