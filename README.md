# Patently Alive（生生事务所）

物种设计 + 生态推演 + 兽医干预的游戏。设计文档见 `docs/`，协作约定见 `CLAUDE.md`。

当前阶段：**阶段 1 · 野猫与鸟岛**（见 `docs/PHASE1.md`）。阶段 0（灰盒推演）已过关。

在线试玩：<https://thuhanliang.github.io/patently-alive/>（`main` 每次更新后自动发布）。

## 运行

需要 Node 22.12 以上。

```sh
npm install
npm run dev        # 本地试玩（默认鸟岛）；地址栏加 ?seed=123 换种子，?speed=100 换倍速，?world=grassland 打开阶段 0 的草原
npm test           # 确定性、内核纯净性等测试
npm run typecheck  # 两遍类型检查：整个项目一遍，模拟内核单独一遍（不带 DOM 类型）
npm run build      # 类型检查 + 打包到 dist/
npm run sweep      # 批量推演：多个种子跑 10 年，打印起伏和报警（WORLD / SEEDS / YEARS / SIZE / SEED0 可调）
```

## 操作

- 拖拽平移，滚轮缩放；`1` 全图，`2` 区域（每片 8×8 格画各物种的群落图标，图标越多那一片越密），`3` 地块（放大后中央区域展开成个体）。
- 空格暂停 / 继续，`.` 单步一天，`[` `]` 切换 1 / 10 / 100 倍速。
- 地址栏加 `?perf=1`：状态栏显示主线程每帧花在脚本上的毫秒数（检查性能用）。
- 右上角切换数据图层（植被 / 各物种密度 / 死亡热力，一次一层）。死亡热力按片显示近期（30 天半衰期）死了多少，可以选物种和死因（被捕食、巢失败、饿死、其他）。
- 上方正中是朱红警报：同一时间只显示最响的一条（濒临消失、比去年同期骤减、饥荒、满意度低、预算见底），地图上用朱红圈标出出事的那一片，点横幅镜头移过去；警报换了或解除都在下面记一行。
- 下方种群曲线：默认每个物种按自己的最高值缩放（看起伏），点一下切换成对数纵轴（比数量）。
- 投放：选物种和数量，打开"投放模式"，在地图上点一下。
- 所有会改变推演的操作都走统一操作接口（`src/sim/session.ts`）并写进操作日志；
  "存档 / 读档"用浏览器里的一个存档位（每个情景一个，清掉网站数据会丢）；"导出存档"下载成文件（操作日志 + 此刻的快照，读档不用重跑），
  "导出日志"只导出操作日志（小，可以从头回放）。"载入存档或日志"两种文件都认：存档直接装回，日志从头回放（三年的局要一分多钟）。

## 鸟岛里有什么（阶段 1，开发中）

一座主岛加三座离岸小岛。本地的双斑鸻（地面筑巢，白身黑帽的圆点），外来的船鼠、穴兔、野猫（猫和兔开局只在主岛）。
参数来源和建模假设见 `docs/MODEL.md`。现在能看到的：

- 不管不顾时鸟每年少一成左右：鼠和猫找到地上的窝，蛋和雏鸟被吃掉；成鸟会飞，不容易被抓。
- 灌丛是窝的掩护：灌丛格的颜色随灌丛多少变化，兔子多的地方几年下来会褪色。
- 右上角"兽医箱"：猫笼、鼠笼（选好放几晚、抓到哪些就移除），夜间搜捕（移除一种动物），体检采样（抓一种检查后放生），找尸体做尸检，防兔网、防捕食者围栏。
  选好后点"放置"，再点地图；围栏点两下（起点、终点）。
  地图上蓝色方块是陷阱、实线圈是搜捕范围、虚线圈是采样范围、带十字的圆圈是找尸体的范围、蓝线是围栏（淡的还在架）。
  左侧"野外记录"列出抓到了什么、找到的尸体；点一具尸体打开临床口吻的尸检报告（咬痕、齿距、体况；结论按齿距列出体型相符的动物）；点一条捕获记录打开检查卡（体重、体况、年龄、胃内容物），
  下面的"抽样推断"按最近 90 天的检查记录估计偏瘦、幼体、雌性的比例和胃里有什么，带 95% 置信区间。每样工具花预算、占一支兽医队若干天；扑杀会降低满意度（扑杀本地鸟降得最多）。
- 情景里是管理员身份，不能投放动物；地址栏加 `?sandbox=1` 可以把鸟岛当沙盒玩（资源不限、可以投放）。
- 开局先读档案馆的历史卡和委托信。委托三年，每 90 天（一季）结算一次：恢复、稳定度、多样性、花费、福利五项分开打分（公式见 `docs/MODEL.md`），
  满意度跟着鸟的恢复变，委托人按满意度拨下一季经费。三年结束有总结页，之后只能看、不能再动手。找鸟的尸体最好在繁殖季（2–5 月）。

## 草原里有什么（阶段 0）

`?world=grassland` 打开。田鼠、穴兔两种食草动物，伶鼬、白鼬两种小型捕食者。参数来自 PanTHERIA、AnAge（见 `docs/DATA_CHECK.md`、`LICENSES-DATA.md`），
建模假设和调参记录见 `docs/MODEL.md`。值得看的：

- 季节：春夏繁殖、冬季减少，植被跟着季节涨落。
- 田鼠–伶鼬周期：伶鼬跟着田鼠涨，涨过头把田鼠吃下去，自己再跟着跌，约 6 年一轮（头一轮要等 4–5 年，用 100x）。
- 白鼬守领地、数量稳；田鼠少的年份它多吃兔子，兔子也跟着起伏。

## 目录

- `src/sim`：模拟内核。纯 TS、固定步长、带种子随机数；不引用渲染、DOM 和系统时钟。
- `src/runtime`：推演宿主。推演在 Web Worker 里跑（`simWorker.ts`），主线程只渲染、收输入；
  Worker 每帧发一份"视图"（推演状态的快照 + 资源、结算、警报），操作照样走 `Session.submit`。
- `src/render`：画面（PixiJS），只读推演状态。
- `src/ui`：界面。
- `src/data`：数据文件与 schema。
- `tests`：测试。
- `scripts/data`：外部性状数据库的下载与核对（`npm run data:fetch`、`npm run data:check`）。
- `docs/MODEL.md`：推演用到的每个数字从哪里来（数据 / 规律 / 假设）、可调范围。
- `handoff/`：需要在本地完成的任务。
