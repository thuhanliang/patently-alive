# 010 第 1d 轮：可以走的工作间（2026-11-24，12 张）

四种：A 厢式货车、B 拖挂房车、C 小屋 / 船屋、D 篷车。每种三张：1 里面（主画面）、2 在世界里、3 在路上。
用户：比之前都更符合想法；"在世界里"的地图画风有不一致；"在路上"那组画风变了，只作参考；"在世界里"有很多植物好看。

## 结论：B 房车的里面做主画面

`B1-caravan-inside.jpg` 是 010 到现在最接近"不用教也会玩"的一张。每样东西都是它看起来的样子：

| 画里的东西 | 玩家看到它会想做什么 | 对应游戏里的 |
| --- | --- | --- |
| 门上的投信口、门边碟子里的一叠信 | 拿起来拆 | 收到求助（委托） |
| 台面上毛毡格子里的纸偶零件、旁边的铆钉碗、剪刀、草图 | 拼起来 | 设计台 |
| 墙上柜子里一卷卷图纸 | 抽一卷展开 | 现有技术（前人的设计） |
| 晾衣绳上夹着的一排动物卡 | 一张张看 | 自己的专利 |
| 窗下木框托盘里的纸雕岛；窗外就是那片梯田和河 | 凑近看，点它 | 走进岛（桌上的岛 = 窗外那片地方的缩影） |
| 门边的皮箱（绷带、药瓶、工具） | 打开、带上 | 兽医箱、出诊 |
| 地板上的泥脚印、炉子上的水壶、两只杯子 | （不用做什么）| 有人住着；脚印说明动物来过 |

还有两点也对：岛在画面里约占十分之一；门开着，外面撑着篷子、摆着折叠桌——车已经"支开"了。

其余几张能借的：
- A 货车里面：后门整个敞开，门外就是海岸，"出门就是现场"最直接。A2 在世界里的比例最好——车小小一个停在岸边、撑着篷子、放下踏板，像地图上的标记。A3 车身上的贴纸、车顶的箱子，就是"会长大"的样子。
- B3 在路上：房车由一辆皮卡拖着——正好接上用户最早的"皮卡"想法：皮卡拖着房车走，到了把房车停下、支开。
- C1 的岛放在一只搪瓷盆里，盆里有水，很可爱（岛泡在一盆海里）；但 C 的里面是固定小屋、外面是船，前后对不上。
- D 篷车温暖明亮，但拓荒西部的联想太强，而且画面太满、太对称。

## 画风

这一轮是水彩插画，不是纸。游戏里的岛已经是真的卡纸纸雕，工作间也要和它是同一种东西：**整辆房车做成一件卡纸模型**（像一只能打开的纸娃娃屋），墙、柜子、杯子都是卡纸和木片做的，看起来真的能做出来，也和"以后导出打印 A4 纸雕"是同一件事。"在世界里"那组的地图不用参考，我们的岛就是游戏里现在那样；只参考营地的样子和比例，以及植物的样子（伞形的蕨、一丛丛开花的草、芦苇）。
