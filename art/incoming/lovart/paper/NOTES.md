# 剪纸方向：代码 demo 和 Lovart 示意图的对比（2026-10-22）

- 示意图：`lovart-field.jpg`（提示词 1 跑出来的现场画面）。
- 代码画的：`demo-region.jpg`（区域视图）、`demo-close.jpg`（近景）、`demo-island.jpg`（全岛）。
- 在线打开：`paper.html`（本地 `npm run dev` 后访问 `/paper.html`）。
  - 参数：`?seed=1&days=40&view=region|island|close`；
  - 按 1、2、3 切换视图，滚轮缩放，拖动平移。

## demo 做了什么

- **地形完全由推演的格子生成**（鸟岛，种子 1，推演 40 天）：
  - 离岸距离场分出深海、中海、浅海、浪花、海岸几层，草地和灌丛各用一层指示场；
  - 每层纸有低频扭曲（海岸线不跟着格子走）、带纤维毛刺的白色撕边，以及往右下方落的投影；
  - 草地和灌丛的颜色随植被量泛黄：被吃坏的地方会变成枯色纸。
- **贴纸按格子撒**：
  - 草丛来自 P1，被啃的地方换成稀疏草丛；
  - 灌丛来自 P2，植被量低时换成稀疏灌丛或枯枝；
  - 岩石、卵石、漂流木、海带来自 P3；
  - 投影由代码加：同一张图压扁、斜切、模糊。
- **代表单位**：
  - 每个物种按格子数量聚成几个代表，每格只归给最近的一个代表，所以数量签加起来正好等于总数；
  - 大小按体重的 0.12 次方压缩：鸟 2.6 格、鼠 3.0、兔 3.8、猫 4.3。
  - 动物用 P7 整只剪纸（2026-10-22 起）：每只代表从五个姿势里随机选一个；鸟一半趴在巢里，一半站在巢边。
  - 同一物种按站姿的剪纸面积统一缩放，避免长尾巴、长耳朵影响大小。
  - P7 缺失时退回代码画的占位木偶。
- **标记和界面**：P6 的笼子、三角、圆环、木桩加代码画的蓝绳，朱红警报配被毁的巢，界面底板是撕边纸条。
- **确定性**：同一个种子画两次，除了左上角的耗时文字，像素完全一样。

## 和示意图的差距

| 方面 | 现状 | 怎么补 |
| --- | --- | --- |
| 海岸分层、白边、投影 | 已经接近示意图 | 可以再加一层"海岸岩壁"的侧面 |
| 纸纹 | 已换成 P4 真纸纹（镜像平铺，四边各裁 8 像素去品红边） | 纸纹本身不是无缝的，靠镜像平铺遮住接缝 |
| 草地底色 | P4 草绿 + 植被量低时混枯色；早春偏黄绿 | 草地里加一层"草皮"小贴纸（P1 第 3 行）铺密 |
| 草丛、灌丛 | 素材本身很好，数量够 | 变体越多越好；灌丛可以按大小分档 |
| 地形立体感 | 示意图有岩石侧面和高差，代码里是平的 | 推演没有高程；要的话做成纯装饰的"台地边缘"贴纸 |
| 动物 | P7 整只剪纸，质感和地形统一 | 之后接 V3 参数化部件；P7 的鸟嘴偏长，更像燕鸥，不像双斑鸻 |
| 比例 | 压缩比例；站立的兔、直立的鼠显得偏大 | 继续试玩调整：按姿势再修正一次，或者现场只用低姿势 |
| 光 | 只有投影，没有整体光感 | 加一层整体调色（暖色暗角），以后纪录片的光也从这里来 |

## 素材处理

- 原图在 `raw/`（从聊天里拿到的 JPEG）。
- 切图脚本：`python3 -I scripts/art/slice_sheet.py <素材表> public/proto/paper/<表名> [最大边长]`。
  - 它按品红抠背景、去溢色，再按行列空隙切出每个素材，并写 manifest.json。
  - 你上传 PNG 原图后，重新跑一遍即可。

### 试过、放弃了的

- **纸板台阶**（陆地分几层抬高、露出棕色侧面）：层间的厚度和缝隙示意图里没有，已删。
- **一片片叶子拼草丛、灌丛**：不够整体，也不是好的画法。
  - 只保留 P8 叶片铺地面（见下）；
  - 代码画的植物改成景观表现图的画法：细草叶束、分层剪影（`plants.ts`）。
  - 留作 `plants=code` 对照，默认不用。

### 现在的做法

- **地面**：
  - 草地和灌丛的地面去掉白边和投影，边缘柔和过渡。白色撕边只留在水陆之间。
  - 草地上铺两层：一层 P8 小叶（约兔子身长的四分之一，左上亮边、右下小影子），一层 P1 草皮贴片。
    - 都直接画进地形图，平躺在地上；
    - 只改明暗，颜色仍由推演决定。
  - 海滩上铺 P3 卵石堆。
- **植被轮廓只有一套**：同一张灌丛场（和地形绘制同样的扭曲、同样的门槛）同时决定两件事：
  - 树冠下的暗地面（往里收一点、和草地混一半）；
  - 灌丛摆在哪：按树冠的视觉中心判断，不按脚。
  - 灌丛密密地叠成一整片，轮廓就是植物本身的剪影。
- **植物**：草丛用 P1，灌丛用 P2 里圆而密的那些（压暗，叠成示意图里的深绿一团）。
  - **大小**按兔子身长定（量自示意图）：
    - 一丛草约和兔子一样长；
    - 一团灌丛约是兔子的 1.1–1.7 倍。
  - **草丛**成片长（低频噪声），被啃得越狠越稀、越黄。植被量低时：
    - 草丛换 P1 第 5 行（被啃过的）；
    - 灌丛换 P2 第 5、6 行。
  - **投影**：所有立牌的投影都倒向右下（光从左上来）。
- **海岸**：
  - 水边按低频噪声成堆地摆 P3 岩石，成了示意图里那种岩岸；
  - 靠草地的一侧用长地衣的石头；
  - 深一点的水里有海草，沙滩上零星有漂木和贝壳。
- **动物**：每个代表单位按数量放 1–4 只，姿势各不相同（示意图里一群兔子就是三四只）。
  - 数量签才是真数，单独立一块，永远在最上面。
  - 拉远成全岛地图时只留一只。
- **不挡信息**：挡在动物、数量签、标记、警报前面的植物和石头不摆。
- **镜头**（`camera.ts`）：
  - 全岛视图正俯视；
  - 区域视图倾斜约 30°（接近示意图的角度）；
  - 近景 50°。
  - 植物、动物、标记始终正对镜头，像 SketchUp 的"面向相机"组件；地面只在竖直方向压扁。
  - 所有坐标换算只走 `project`、`unprojectGround`、`anchor`。滚轮缩放时，鼠标下的那块地面不动。
- **整体调子**：屏幕四角偏暖压暗。

### 开销（种子 1，本机无头浏览器）

- **启动**：地形约 1.7 秒、铺叶约 1.0 秒、摆植物约 0.04 秒。都只在载入时做一次。
- **显存**：地形和植被贴图约 16 MB，不含 P 系列素材本身。
- **帧时间**：无头浏览器是软件渲染，测出来的帧间隔没有参考意义，要在真机上看。

### 和示意图还差的

- **示意图是一张画，这里是按推演数据摆出来的**：草丛、灌丛、岩石的位置和疏密跟着真实的地形和植被量走，构图不会和示意图一模一样。
- **海岸**：示意图的岩岸更高、更连续；这里只是成堆的岩石立牌，没有连续的崖壁。
- **水面**：示意图的海水有明显的笔触纹理，浪花是好几道厚的白色花边；这里用 P4 纸纹和撕边，浪花偏细。
- **示意图的海草是金黄色的**，P3 里的海草偏绿褐。
- **动物和标记**：仍是 P7、P6 整张剪纸。
  - 示意图里的猫画成了老虎，这里按比例用的是家猫；
  - 鸟是 P7 的样子，嘴偏长。
- **遮挡**：所有立牌按脚的位置排前后，没有更细的遮挡。
