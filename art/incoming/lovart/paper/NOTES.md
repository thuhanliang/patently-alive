# 剪纸方向：代码 demo 和 Lovart 示意图的对比（2026-10-22）

- 示意图：`lovart-field.jpg`（提示词 1 跑出来的现场画面）。
- 代码画的：`demo-region.jpg`（区域视图）、`demo-close.jpg`（近景）、`demo-island.jpg`（全岛）。
- 在线打开：`paper.html`（本地 `npm run dev` 后访问 `/paper.html`）。
  - 参数：`?seed=1&days=40&view=region|island|close`；
  - 按 1、2、3 切换视图，滚轮缩放，拖动平移。

## demo 做了什么

- **地形完全由推演的格子生成**（鸟岛，种子 1，推演 40 天）：
  - 离岸距离场分出深海、中海、浅海、浪花、海岸几层，草地和灌丛各用一层指示场；
  - 每层纸有低频扭曲（海岸线不跟着格子走）、带纤维毛刺的白色撕边，以及往右下方落的投影；
  - 草地和灌丛的颜色随植被量泛黄：被吃坏的地方会变成枯色纸。
- **贴纸按格子撒**：
  - 草丛来自 P1，被啃的地方换成稀疏草丛；
  - 灌丛来自 P2，植被量低时换成稀疏灌丛或枯枝；
  - 岩石、卵石、漂流木、海带来自 P3；
  - 投影由代码加：同一张图压扁、斜切、模糊。
- **代表单位**：
  - 每个物种按格子数量聚成几个代表，每格只归给最近的一个代表，所以数量签加起来正好等于总数；
  - 大小按体重的 0.12 次方压缩：鸟 2.6 格、鼠 3.0、兔 3.8、猫 4.3。
  - 动物是代码画的占位剪纸木偶，等 P7 和参数化部件（V3）出来再换。
- **标记和界面**：P6 的笼子、三角、圆环、木桩加代码画的蓝绳，朱红警报配被毁的巢，界面底板是撕边纸条。
- **确定性**：同一个种子画两次，除了左上角的耗时文字，像素完全一样。

## 和示意图的差距

| 方面 | 现状 | 怎么补 |
| --- | --- | --- |
| 海岸分层、白边、投影 | 已经接近示意图 | 可以再加一层"海岸岩壁"的侧面 |
| 纸纹 | 用代码生成的纸，偏平 | P4 纸纹放到 `public/proto/paper/P4/` 后自动换成真图 |
| 草地底色 | 偏平、偏亮 | 换 P4；草地里加一层"草皮"小贴纸（P1 第 3 行）铺密 |
| 草丛、灌丛 | 素材本身很好，数量够 | 变体越多越好；灌丛可以按大小分档 |
| 地形立体感 | 示意图有岩石侧面和高差，代码里是平的 | 推演没有高程；要的话做成纯装饰的"台地边缘"贴纸 |
| 动物 | 代码占位，比较简陋 | P7 整只剪纸，之后接 V3 参数化部件 |
| 比例 | 压缩比例，看着合理 | 继续试玩调整 |
| 光 | 只有投影，没有整体光感 | 加一层整体调色（暖色暗角），以后纪录片的光也从这里来 |

## 素材处理

- 原图在 `raw/`（从聊天里拿到的 JPEG，P4 缺）。
- 切图脚本：`python3 -I scripts/art/slice_sheet.py <素材表> public/proto/paper/<表名> [最大边长]`。
  - 它按品红抠背景、去溢色，再按行列空隙切出每个素材，并写 manifest.json。
  - 你上传 PNG 原图后，重新跑一遍即可。
