# 剪纸方向：代码 demo 和 Lovart 示意图的对比（2026-10-22）

- 示意图：`lovart-field.jpg`（提示词 1 跑出来的现场画面）。
- 代码画的：`demo-region.jpg`（区域视图）、`demo-close.jpg`（近景）、`demo-island.jpg`（全岛）。
- 在线打开：`paper.html`（本地 `npm run dev` 后访问 `/paper.html`）。
  - 参数：`?seed=1&days=40&view=region|island|close`；
  - 按 1、2、3 切换视图，滚轮缩放，拖动平移。

## demo 做了什么

- **地形完全由推演的格子生成**（鸟岛，种子 1，推演 40 天）：
  - 离岸距离场分出深海、中海、浅海、浪花、海岸几层，草地和灌丛各用一层指示场；
  - 每层纸有低频扭曲（海岸线不跟着格子走）、带纤维毛刺的白色撕边，以及往右下方落的投影；
  - 草地和灌丛的颜色随植被量泛黄：被吃坏的地方会变成枯色纸。
- **贴纸按格子撒**：
  - 草丛来自 P1，被啃的地方换成稀疏草丛；
  - 灌丛来自 P2，植被量低时换成稀疏灌丛或枯枝；
  - 岩石、卵石、漂流木、海带来自 P3；
  - 投影由代码加：同一张图压扁、斜切、模糊。
- **代表单位**：
  - 每个物种按格子数量聚成几个代表，每格只归给最近的一个代表，所以数量签加起来正好等于总数；
  - 大小按体重的 0.12 次方压缩：鸟 2.6 格、鼠 3.0、兔 3.8、猫 4.3。
  - 动物用 P7 整只剪纸（2026-10-22 起）：每只代表从五个姿势里随机选一个；鸟一半趴在巢里，一半站在巢边。
  - 同一物种按站姿的剪纸面积统一缩放，避免长尾巴、长耳朵影响大小。
  - P7 缺失时退回代码画的占位木偶。
- **标记和界面**：P6 的笼子、三角、圆环、木桩加代码画的蓝绳，朱红警报配被毁的巢，界面底板是撕边纸条。
- **确定性**：同一个种子画两次，除了左上角的耗时文字，像素完全一样。

## 和示意图的差距

| 方面 | 现状 | 怎么补 |
| --- | --- | --- |
| 海岸分层、白边、投影 | 已经接近示意图 | 可以再加一层"海岸岩壁"的侧面 |
| 纸纹 | 已换成 P4 真纸纹（镜像平铺，四边各裁 8 像素去品红边） | 纸纹本身不是无缝的，靠镜像平铺遮住接缝 |
| 草地底色 | P4 草绿 + 植被量低时混枯色；早春偏黄绿 | 草地里加一层"草皮"小贴纸（P1 第 3 行）铺密 |
| 草丛、灌丛 | 素材本身很好，数量够 | 变体越多越好；灌丛可以按大小分档 |
| 地形立体感 | 示意图有岩石侧面和高差，代码里是平的 | 推演没有高程；要的话做成纯装饰的"台地边缘"贴纸 |
| 动物 | P7 整只剪纸，质感和地形统一 | 之后接 V3 参数化部件；P7 的鸟嘴偏长，更像燕鸥，不像双斑鸻 |
| 比例 | 压缩比例；站立的兔、直立的鼠显得偏大 | 继续试玩调整：按姿势再修正一次，或者现场只用低姿势 |
| 光 | 只有投影，没有整体光感 | 加一层整体调色（暖色暗角），以后纪录片的光也从这里来 |

## 素材处理

- 原图在 `raw/`（从聊天里拿到的 JPEG）。
- 切图脚本：`python3 -I scripts/art/slice_sheet.py <素材表> public/proto/paper/<表名> [最大边长]`。
  - 它按品红抠背景、去溢色，再按行列空隙切出每个素材，并写 manifest.json。
  - 你上传 PNG 原图后，重新跑一遍即可。

## 第二版：叶片拼植被 + 地面铺叶 + 纸板台阶 + 随缩放倾斜（2026-10-22）

针对两个问题："素材中间的深色显得怪、堆叠感强"，以及"和示意图的细节差距"。

- **截图**：`demo-v2-region.jpg`、`demo-v2-close.jpg`、`demo-v2-island.jpg`；第一版的截图（`demo-*.jpg`）保留作对照。
- **现在默认就是第二版**，每一项都能单独关掉对照：
  - `?mode=stickers` 回到 P1、P2 整张贴纸；
  - `&terraces=0` 去掉台阶；
  - `&tilt=0` 始终俯视。

### 叶片（P8，`src/proto/paper/leaves.ts`）

- P8 六行：草簇、披针叶、阔叶、裂叶、复叶和蕨、小叶和花。
  - 切图：`python3 -I scripts/art/slice_sheet.py raw/P8.webp public/proto/paper/P8 160`。
  - 载入时去色并把亮度归一，只留叶脉和纸纹的相对明暗；颜色全部由代码给。
- **草丛**：几簇 P8 草簇加零散的长叶拼成。
  - 后排暗、前排亮，整丛下暗上亮（梢部偏黄）。
  - 簇数随草本植被量变化，被啃得越狠越稀、越枯。
  - 草丛成片长（低频噪声），不是均匀撒。
- **灌丛**：阔叶、裂叶、复叶排成半圆顶，从里往外画。
  - 里面暗、外沿亮，左上亮、右下暗。
  - 白边只在整丛外轮廓上（先画所有衬底、再画叶子）。
  - 每丛明暗略有差别。
- **叶缝都是透明的**：不再有烤进素材的深色中心，投影和明暗都由代码按同一个光源（左上）给。

### 地面铺叶

- 草地和灌丛下面铺满一层 P8 小叶：每片先画一点往右下的暗影，再画本身；海岸铺卵石。
- 只改明暗、不改颜色：地面颜色仍由推演决定，被啃的地方照样泛黄。
- 叠了一层低频斑块：深色苔藓和浅色草皮交替，接近示意图里"一片片铺出来"的地面。

### 纸板台阶（`src/proto/paper/terraces.ts`）

- 陆地按离岸距离加低频噪声分成 3 层：
  - 第一层有的地方紧贴水边成了海边的崖，有的地方让出一条海滩；
  - 往里两层是台地。
- **纯装饰**：推演里没有高程，台阶不影响任何结果。
- 每层顶面带米白纸边和纤维毛刺，往右下落影子。
- 侧面用卵石灰的纸纹，同一个剪影往下叠 12 份：越往下越暗，每隔几份亮一点，像一层层纸板的边。

### 随缩放倾斜的镜头（`src/proto/paper/camera.ts`）

- **按缩放倾斜**：
  - 缩放 0.7 以下完全俯视（全岛像地图）；
  - 往近拉逐渐倾斜，到近景 2.6 倍时 50°；
  - 用的是斜二测，不是透视。
- **地面和立起来的东西分开处理**：
  - 地面（地形、投影）只在竖直方向压扁；
  - 台阶按高度往上抬，露出侧面；
  - 草丛、灌丛、动物、标记是立起来的纸片，始终正对镜头，像立体贺卡。
- **一套坐标换算**：所有换算只走 `project`、`unprojectGround`、`anchor`。滚轮缩放时，鼠标下的那块地面在缩放和倾斜前后不动。

### 开销（种子 1，本机无头浏览器）

- 启动：地形约 1.5 秒、铺叶约 1.3 秒、台阶约 0.6 秒、烤植被约 0.2 秒。
  - 都只在载入时做一次，之后不再计算。
- 显存：地形和植被贴图约 57 MB。
  - 底图 16 MB，三层顶面和侧面按有内容的范围裁过。
  - 还没算 P 系列素材本身。
- 帧时间：无头浏览器是软件渲染，测出来的帧间隔（0.2–1.4 秒）没有参考意义，要在真机上看。
  - 每帧的主要开销：每层 12 张侧面贴图，加上投影层的模糊。

### 已知问题

- **遮挡不完全对**：立起来的东西统一画在所有地形之上。
  - 所以低处、紧贴在高一层台阶后面的草丛或动物，会盖到台阶的侧面上，而不是被台阶挡住。
  - 反过来，按层穿插画会把站在台阶前面的东西的上半截切掉，更难看，所以先这样。
- 台阶边在内陆有时横穿草地中间，像等高线。层数、高度、门槛都是 `terraces.ts` 顶部的常数，可以再调。
- 代表单位正好站在台阶边上时，会半悬在侧面上。
- 动物和标记仍然是 P7、P6 整张剪纸，没有拆成部件（V3）。
