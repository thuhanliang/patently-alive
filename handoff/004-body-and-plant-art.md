## A · 现有部件的完整线稿

规格同 003 B1：512×512、透明背景、只有蓝图蓝线条、不填色、侧面、头朝右、躯干中心在画布中心。
**每个部件要两个尺度的版本**：`-s`（鼠到猫大小的躯干比例）和 `-l`（狐狸到鹿大小），因为体型变了，同一个部件的比例也会变。
文件名：`part-<槽>-<部件 id>-<s|l>.png`，部件 id 和游戏数据一致（`src/data/design/parts.json`）。

| mouth | `carnassials` | 裂齿 | 食肉动物短吻，犬齿和剪刀状裂齿 |
| mouth | `mixed_teeth` | 杂食齿 | 中等吻长，牙型混合 |
| mouth | `pointed_snout` | 尖吻细齿 | 细长的鼻子贴地，细小的牙 |

## B · 体内系统的剖面层（体重分配用）

阶段 3.5 的塑形是把体重分给五个系统，设计台上要能"透视"看到它们，份额变了，图层跟着变粗变细。

- 规格：512×512、透明背景、蓝图蓝线稿，**和 A 的躯干完全对齐**（同一比例尺、同一中心），可以叠在 A 上。
- 每个系统画**三档**：`-low`（份额 0.5 倍）、`-mid`（默认）、`-high`（2 倍），我在中间插值或直接换图。
- 每套按体型分四足兽（`-quad`）和鸟（`-bird`）两套。
- 文件名：`body-<系统>-<档>-<quad|bird>.png`。

| 系统 | 画什么 | 三档的差别 |
| --- | --- | --- |
| `skeleton` | 骨架：脊柱、肋骨、四肢长骨 | 骨的粗细；high 的腿骨像柱子 |
| `muscle` | 主要肌群的轮廓线（腿、肩、颈） | 肌肉的厚度 |
| `heart` | 心脏和主动脉、颈动脉（简化） | 心脏大小、血管粗细 |
| `fat` | 皮下脂肪的轮廓（点画或虚线） | 脂肪层厚度 |

消化道单独画，因为它取决于消化部件，不只是份额。文件名 `gut-<部件 id>-<quad|bird>.png`：

| 部件 id | 画什么 |
| --- | --- |
| `simple_stomach` | 单胃 + 不长的小肠 |
| `hindgut_fermenter` | 单胃 + 很大的盲肠（盘曲） |
| `short_gut` | 很短很直的肠 |
| `crop_gizzard` | 嗉囊 + 砂囊（里面几颗小石子） |
| `rumen`（后续，反刍） | 四室胃 |

育幼性状各画一张小插图（`rearing-<id>.png`，256×256，墨线 + 平涂）：`altricial` 窝里光溜溜闭眼的幼崽；`precocial` 刚出生就站起来的幼崽。

## C · 尸检插图：新死因

尸检报告里配一张小图说明死因。风格：**田野笔记的解剖速写**，墨线 + 少量平涂，纸色底，不血腥（温馨的基调：像博物馆标本图，不是外科照片）。
规格 512×384，文件名 `necropsy-<死因>.png`。

| 死因 | 画什么 |
| --- | --- |
| `fracture` 承重骨折 | 一根腿骨的应力骨折线和骨痂（局部放大），旁边小比例的整只轮廓标出位置 |
| `dystocia` 难产 | 腹部剖面示意：胎儿（或一枚过大的卵）卡在产道（简化成线稿，不写实） |
| `malnutrition` 营养不良 | 消瘦的体况（肋骨、髋骨突出的轮廓）+ 胃里没消化的粗纤维 |
| 以后：`hypothermia` 失温、`overheating` 过热、`circulatory` 循环衰竭 | 先不急，可以放到 E 之后 |

## D · 植物类型和植被状态

阶段 3.5 把"植被"拆成多种植物类型，而且会被吃坏。地图上要看得出**是什么植物**和**被吃成了什么样**。

- 风格：沿用 002 的水彩地形（柔和、低对比），俯视，**可平铺**（四边无缝），256×256。
- 文件名：`plant-<类型>-<状态>.png`。

| 类型 | 说明 |
| --- | --- |
| `grass` 草本 | 低矮的草地（现有的"草地"） |
| `tussock` 丛生草 | 一簇一簇的高草丛，能藏窝 |
| `shrub` 灌丛 | 现有的"灌丛"，木本 |
| `herb` 杂草与种子植物 | 开花、结籽的草本，种子是食物 |
| `forest` 林地（后续） | 树冠俯视 |

每种画四个状态：

| 状态 | 画什么 |
| --- | --- |
| `lush` | 茂盛 |
| `grazed` | 被啃过：变矮、变稀，露出一点地面 |
| `bare` | 啃到贴地，大片裸地，只剩根茬 |
| `degraded` | 退化：土壤裸露、开裂或沙化，长出少量杂草（"吃坏了"之后的样子） |

另外一张图例小图：每种植物的**单株插图**（256×256，墨线 + 平涂），给图层说明和设计台的"这片地能吃什么"用：
`plant-icon-<类型>.png`。

## E · 后续部件（先画，以后用）

这些是以后加体温、循环、感官、防御时的部件，规格同 A（两个尺度、蓝图线稿）。不急，A–D 都做完再说。

| 类 | 部件 | 说明 |
| --- | --- | --- |
| neck 颈 | `neck-short`、`neck-long`、`neck-very-long` | 循环检查用：头越高，心脏越累 |
| ears 耳 | `ears-small`、`ears-large`、`ears-round` | 体温：大耳朵散热（艾伦法则） |

| armor 防御 | `spines`（刺）、`scales`（鳞甲）、`shell`（壳） | 防御 |
| skin 体表 | `bare-skin`（裸皮）、`blubber`（厚脂肪层，剖面） | 体温 |
| body 体型 | `body-biped`（直立两足）、`body-columnar`（大型柱状腿） | 骨骼检查用的站姿 |

## F · 风格对比参照（只给实验页）

阶段 3.5 第 10 步会做一个**只在开发时打开的实验页**，用几种画法画同一只设计好的动物，给你比较手感。
正式游戏仍然只用田野笔记（`DECISIONS.md`），这些只是参照，不进游戏。

- 同一只动物（用 002 的野猫或兔子）画三种风格，各一张 512×512：
  - `style-fieldnotes.png`：田野笔记（参照现有风格锚）；
  - `style-handdrawn.png`：铅笔或钢笔手绘，线条有抖动、有涂改痕迹；
  - `style-pixel.png`：像素画，64×64 画好再放大到 512（最近邻），配色仍用我们的主色。
