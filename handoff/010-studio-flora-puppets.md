# 010 · 工作室、植物图鉴、参数化纸偶（Lovart）

状态：待发（2026-11-22；第 1 轮 2026-11-24 重写）。三轮互相独立，可以分开发。都是**参考图**，不是直接贴进游戏的素材：游戏里的东西由代码按这些图做出来（形状、厚度、光影都是真的几何）。

共同的要求（每一轮都附在提示词最后）：
- 像一张实拍的手工纸艺作品照片：真的卡纸、看得见纸的厚度和断面、层与层之间的投影；不要插画、不要 3D 渲染的塑料感。
- 一切都要**做得出来**：用刀和剪子能从卡纸上裁下来、粘起来、用铆钉钉起来。
- 不要文字、不要水印。

## 第 1 轮：工作室定调图（重写于 2026-11-24）

**为什么重写**：第一版提示词和第一版工作室都照着用户家书桌角落的照片，一件件列了墙纸、挂画、晶簇、天平……用户的评价是"刻意且粗糙的模仿，思路被照片限制死了"。

其余的——这是什么地方、多大、什么时代、什么光、放什么东西——请 Lovart 自己发明，并且先给出**很多个彼此很不一样的方向**，选定以后再画精细图。

### 第一条消息（附 A–E 五张图）

```
我们在做一款游戏《生生事务所》，想请你一起发明它的"家"。

游戏是这样的：玩家经营一家小小的"物种专利事务所"。有人遇到了生态上的麻烦（岛上的草被啃光了、鸟快没了……）来信求助；玩家用纸片和黄铜铆钉拼出一种新的动物，放到一座岛上，看世界怎么"验收"它——它活不活得下去，会不会把别的东西吃光。核心的乐趣是：设计是一个假设，世界是一场实验。气质是温柔的、好奇的、带一点点博物学和科学的味道。

附图是游戏里已经做好的岛：整座岛按等高线用一张张卡纸叠起来，海是由深到浅的蓝纸，岸边一条白色浪花纸，草、花、灌木都是立着的剪纸。这个材质语言已经定了。

现在要设计的是玩家每次回来的那个"地方"。它要承担这几件事（这里只说要做的事，不规定是什么东西）：
1. 收到新的求助；
2. 设计、拼装一只动物（铆钉纸偶）；
3. 翻看以前的人设计过的动物；
4. 看自己已经得到的"专利"；
5. 走进岛里。

唯一已经定下的是第 5 件：这座岛在这个地方是一件拿得起、摸得着的实物（附图那样的纸雕，大概 A4 大小，真的能用卡纸做出来）。玩家点它，镜头会一直扎进去，变成全屏的岛。

其余全部交给你：这是一个什么地方（不一定是书房，不一定是一张桌子，也不一定是室内），多大，什么年代、季节、时间，光从哪里来，用什么颜色，前面 1–4 件事分别由什么东西、什么动作来承担——请你来发明。希望每一件都有一点让人想伸手去碰的巧思。

请先不要画精细图。请给我 8 个彼此差别很大的方向（地点、尺度、光、气质都不一样，不要只是同一张桌子换个颜色），每个方向一张小草图，加三四句话：这是哪里；岛放在哪儿、怎么放；1–4 件事分别是什么东西；人第一眼看到什么。

请避开这些：常见的"温馨书房""魔法师小屋""复古博物馆"的套路；把桌子堆满小摆件（东西少而有意义更好）；整张画都是暖黄、米黄色；画面里出现文字。
```

### 第二条消息（从 8 个里挑 2–3 个以后发）

```
我们选了第 __、__、__ 个方向。请把每个方向画成一张 16:9 的定调图：
像一张实拍的手工微缩作品的照片——真的卡纸、看得见纸的厚度和断面、层与层之间的投影；和附图里的岛是同一种材质、同一个世界。
镜头要能直接做成游戏画面：一个固定的机位，那几件能碰的东西都看得清、彼此分开，岛是画面里最想让人点的那一个。
再为每个方向补一张小图：镜头正在扎进岛里的那一瞬间。
```

## 第 2 轮：剪纸植物图鉴（1–2 张，方形）

```
请画一张"剪纸植物图鉴"：浅色卡纸底上，整齐地排着二十几种用彩色卡纸剪出来、立起来的小植物，正面平视，每一株分开、不重叠。
每一株都是两到四张纸叠起来的（茎叶一张、花一张、花心一张……），能看到纸的厚度、边缘的白色断面、纸与纸之间的小投影，脚下有一个插进底板的小纸舌。
要有：矮草丛、带穗的高草、海边弯弯的沙草、雏菊、毛茛、三叶草、海石竹、毛地黄、蒲公英（花和绒球）、蕨、香蒲、
圆灌丛、开黄花的荆豆、结红果的灌丛、杜松、矮松、圆冠小树、被海风吹歪的小树、蘑菇、两三种石头。
颜色饱和但不艳，像手工纸；同一种植物给两三个颜色变化。
```

## 第 3 轮：参数化纸偶（2 张，16:9）

```
我们的动物是"参数化"的纸偶：同一套零件（头、耳、躯干、前后腿、尾、吻）按参数变长变短、变宽变窄、变圆变尖，铆钉钉在关节上。
图一：一张零件表。深绿切割垫上，按部位一行一行摆着同一种零件的不同变体：
耳（圆的、尖的、长的垂耳、没有耳廓）、尾（短的、长的一节节、蓬松的、扁平的）、腿（粗短、细长、跳跃的长后腿）、吻（短的、长的、尖的）、躯干（圆、长、壮）；
每一片零件上画着铆钉孔，纸片边缘有白色断面，零件上有剪纸的花纹色块（虎斑、斑点、浅色的肚子）。
图二：用这些零件拼出来的六只不同的动物站成一排（兔、猫、鼠、鼬、一只鸟、一只玩家自己设计的奇怪动物），每个关节一颗黄铜铆钉，侧面平视，同一种光。
```
