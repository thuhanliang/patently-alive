# 010 · 工作室、植物图鉴、参数化纸偶（Lovart）

状态：待发（2026-11-22）。三轮互相独立，可以分开发。都是**参考图**，不是直接贴进游戏的素材：游戏里的东西由代码按这些图做出来（形状、厚度、光影都是真的几何）。

共同的要求（每一轮都附在提示词最后）：
- 像一张实拍的手工纸艺作品照片：真的卡纸、看得见纸的厚度和断面、层与层之间的投影；不要插画、不要 3D 渲染的塑料感。
- 一切都要**做得出来**：用刀和剪子能从卡纸上裁下来、粘起来、用铆钉钉起来。
- 不要文字、不要水印。

我们在做一款剪纸风格的游戏《生生事务所》：玩家在一间小工作室里用纸片和黄铜铆钉拼出动物，放到一座纸做的岛上，看它们活不活得下去。

## 第 2 轮：剪纸植物图鉴（1–2 张，方形）

```
请画一张"剪纸植物图鉴"：浅色卡纸底上，整齐地排着二十几种用彩色卡纸剪出来、立起来的小植物，正面平视，每一株分开、不重叠。
每一株都是两到四张纸叠起来的（茎叶一张、花一张、花心一张……），能看到纸的厚度、边缘的白色断面、纸与纸之间的小投影，脚下有一个插进底板的小纸舌。
要有：矮草丛、带穗的高草、海边弯弯的沙草、雏菊、毛茛、三叶草、海石竹、毛地黄、蒲公英（花和绒球）、蕨、香蒲、
圆灌丛、开黄花的荆豆、结红果的灌丛、杜松、矮松、圆冠小树、被海风吹歪的小树、蘑菇、两三种石头。
颜色饱和但不艳，像手工纸；同一种植物给两三个颜色变化。
```

## 第 3 轮：参数化纸偶（2 张，16:9）

```
我们的动物是"参数化"的纸偶：同一套零件（头、耳、躯干、前后腿、尾、吻）按参数变长变短、变宽变窄、变圆变尖，铆钉钉在关节上。
图一：一张零件表。深绿切割垫上，按部位一行一行摆着同一种零件的不同变体：
耳（圆的、尖的、长的垂耳、没有耳廓）、尾（短的、长的一节节、蓬松的、扁平的）、腿（粗短、细长、跳跃的长后腿）、吻（短的、长的、尖的）、躯干（圆、长、壮）；
每一片零件上画着铆钉孔，纸片边缘有白色断面，零件上有剪纸的花纹色块（虎斑、斑点、浅色的肚子）。
图二：用这些零件拼出来的六只不同的动物站成一排（兔、猫、鼠、鼬、一只鸟、一只玩家自己设计的奇怪动物），每个关节一颗黄铜铆钉，侧面平视，同一种光。
```
