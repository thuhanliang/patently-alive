# 需要在本地完成的任务

开发环境（云端）不能访问某些外部网站，也不能生成美术图片。这类任务写在这个目录里，
由你在自己的电脑上完成、推送到 GitHub，我再拉取最新提交继续开发。

## 流程

1. 拉取最新代码：`git checkout main && git pull`
2. 每个任务建一个分支：`git checkout -b human/<任务编号>`，例如 `human/001-trait-data`
3. 按任务文档操作，只提交文档里"产出"一节列出的文件
4. 推送：`git push -u origin human/<任务编号>`，然后在对话里告诉我"完成了 001"（开不开 PR 都行）
5. 我拉取分支、按"验收"一节检查、合并进 main，再把任务状态改成"完成"

拿不准的地方，直接把报错或截图发给我。
